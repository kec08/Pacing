The bundled melotts_kr_fp16.onnx is converted from that INT8 model with
tools/convert_melo_model.py (onnx 1.23.2, numpy 2.5.5): dynamic INT8
ConvInteger/MatMulInteger are dequantized to float Conv/MatMul and large
weights are stored as FP16 with a Cast to float. The INT8 kernels synthesized
about 1.5x slower than real time; the float model is about 7x faster.

korean_lexicon.json is generated from g2pkk pronunciations for the app's fixed
running announcement grammar using the model configuration's exact symbol order.
The separate symbols.json in the model repository has a different symbol order
and must not be used with this ONNX checkpoint. Regenerate with
tools/generate_melo_lexicon.py and tools/generate_melo_state_clips.py.
Generation versions: g2pkk 0.1.2, python-mecab-ko 1.3.7,
