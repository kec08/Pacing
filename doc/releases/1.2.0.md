# Pacing 1.2.0

> 2026-08-18 main 반영 ([#118](https://github.com/kec08/Pacing/pull/118))

친구·같이 듣기 경험과 프로필 설정을 다듬은 버전입니다.

- **화면 모드**: 앱 전체를 라이트·다크·시스템 모드 중에서 고를 수 있습니다. ([#96](https://github.com/kec08/Pacing/pull/96))
- **프로필 공개 범위**: 내 프로필 공개 범위를 설정할 수 있고, 인증 화면을 안정화했습니다. ([#112](https://github.com/kec08/Pacing/pull/112))
- **친구 음악**: 친구 음악 카드, 재생 상태, Apple Music 저장을 개선했습니다. ([#94](https://github.com/kec08/Pacing/pull/94))
- **실시간 러너·지도**: 실시간 러너 표시와 러닝 지도 자동 추적을 복구했습니다. 지도에서 내 위치 추적을 켜고 끌 수 있습니다. ([#101](https://github.com/kec08/Pacing/pull/101), [#114](https://github.com/kec08/Pacing/pull/114))
- **같이 듣기·러닝 페이스**: 같이 듣기 프로필과 요청, 러닝 페이스, 최근 활동 정합성을 개선했습니다. ([#103](https://github.com/kec08/Pacing/pull/103), [#107](https://github.com/kec08/Pacing/pull/107))
- **친구 프로필**: 권한 오류와 친구 요청 수락 실패를 고쳤고, 홈의 친구 활동 조회를 바로잡았습니다. ([#110](https://github.com/kec08/Pacing/pull/110), [#114](https://github.com/kec08/Pacing/pull/114))
- **다크 모드·음악 시트**: 내 프로필 다크 모드 표면을 통일하고, 러닝 음악 시트의 앨범 커버와 재생 큐를 맞췄습니다. ([#105](https://github.com/kec08/Pacing/pull/105), [#118](https://github.com/kec08/Pacing/pull/118))
