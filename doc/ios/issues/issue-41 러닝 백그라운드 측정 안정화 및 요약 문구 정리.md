# [feat] 러닝 백그라운드 측정 안정화 및 요약 문구 정리

> **이슈 번호**: #41  
> **유형**: feature  
> **작성일**: 2026-07-15  
> **상태**: Open

## 개요

러닝 중 앱이 백그라운드로 전환되더라도 시간뿐 아니라 거리, 경로, 평균 페이스, 칼로리 계산이 계속 유지되도록 측정 흐름을 안정화합니다.
함께 러닝 종료 요약 화면의 페이스 문구를 사용자 관점에서 더 명확하게 정리합니다.

- 앱 아이콘은 기존 자산 그대로 유지
- 백그라운드 위치 추적으로 거리/경로/평균 페이스/칼로리 지속 갱신
- 종료 요약 상단 문구는 `평균 페이스`로 정리
- 종료 요약 하단 km 단위 상세 문구는 `km 평균 페이스` 의미로 정리

## 사용자 문제

- 현재는 시간만 백그라운드에서 누적되고 거리와 경로는 측정이 멈춤
- 앱을 다시 열어야만 위치 측정이 이어져 실제 러닝 기록이 끊김
- 평균 페이스와 칼로리도 백그라운드 구간이 반영되지 않아 결과 신뢰도가 떨어짐
- 종료 요약 화면의 페이스 문구가 상단 핵심 지표와 하단 km 상세 의미를 충분히 구분해 전달하지 못함

## 작업 범위

1. 백그라운드 측정 누락 원인 점검 및 현재 위치 추적 흐름 확인
2. `Info.plist` background mode 및 위치 권한 설정 보강
3. `LocationManager` 백그라운드 위치 업데이트 처리 보강
4. `RunningViewModel` 거리, 평균 페이스, 칼로리 계산이 백그라운드에서도 이어지도록 동기화 점검
5. 종료 요약 화면 상단 문구를 `평균 페이스` 기준으로 정리
6. 종료 요약 화면 하단 km별 상세 섹션 문구를 `km 평균 페이스` 의미로 정리
7. 앱 아이콘 에셋 변경 없이 유지 여부 확인
8. 실기기 기준 백그라운드 QA 포인트 정리

## 완료 기준

- [ ] 러닝 시작 후 앱이 백그라운드로 전환되어도 거리 측정이 계속 누적된다
- [ ] 백그라운드 상태에서도 경로 좌표가 계속 기록되고 앱 복귀 시 지도 경로가 이어진다
- [ ] 평균 페이스와 칼로리 값이 백그라운드 구간을 포함해 정상 갱신된다
- [ ] 종료 요약 상단 핵심 지표 문구가 `평균 페이스`로 표시된다
- [ ] 종료 요약 하단 km별 상세 섹션 문구가 `km 평균 페이스` 의미로 정리된다
- [ ] 앱 아이콘 에셋은 변경되지 않는다
- [ ] Debug 빌드와 실기기 백그라운드 QA가 가능하다

## 구현 메모

- 현재 `LocationManager`에는 `allowsBackgroundLocationUpdates` 분기가 있으나 `Info.plist`의 `UIBackgroundModes` 누락 여부를 우선 확인해야 함
- 시간은 `Date` 기반 누적으로 유지되지만 거리/경로는 위치 업데이트 지속 여부에 직접 의존함
- 칼로리는 거리 기반 파생값이므로 거리 계산 정상화와 함께 검증 필요
- 하단 km 상세는 현재 1km 랩 데이터 구조를 재사용하는 방향 우선 검토
