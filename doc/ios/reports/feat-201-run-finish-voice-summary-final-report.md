## 구현 요약

러닝 종료 시 iPhone이 운동 완료, 총 거리, 총 시간, 평균 페이스를 한국어 음성으로 한 번 안내하도록 구현했다. 음성 안내 중 음악은 잠시 일시정지되고, 안내 종료 후 기존 음악이 자동 재개된다.

## 변경 사항

- `RunCompletionVoiceAnnouncement` 모델 추가
  - 총 거리, 경과 시간, 평균 페이스를 한국어 문장으로 포맷
  - 1시간 이상 경과 시간과 초 단위를 지원
  - 평균 페이스를 계산할 수 없는 경우 “평균 페이스 정보 없음”으로 안전하게 안내
- `RunningViewModel.stop()`의 실제 종료 확정 시점에 종료 안내 연결
- 마지막 킬로미터 음성이 진행 중이면 종료 요약 음성으로 교체
- iPhone 버튼과 Watch 종료 명령이 동시에 도착해도 첫 종료 요청만 처리하도록 상태 가드 추가
- 종료 음성 문구·경계값 관련 단위 테스트 추가

## 계획서 대비 변경 사항

| 항목 | 계획 | 실제 구현 | 사유 |
|------|------|-----------|------|
| 종료 안내 수치 | 거리·시간·평균 페이스 안내 | `overallAveragePace`를 사용해 종료 요약 화면과 같은 기준으로 안내 | 화면과 음성 수치 일치 보장 |
| 양방향 종료 | 중복 없이 한 번 안내 | `stop()` 진입 상태 가드 추가 | iPhone·Watch 종료 명령 경합으로 발생한 실제 중복 안내 보완 |
| 음악 처리 | 안내 후 자동 재개 | #200의 음성 중 음악 일시정지·자동 재개 정책 재사용 | 검증된 공통 오디오 정책 유지 |
