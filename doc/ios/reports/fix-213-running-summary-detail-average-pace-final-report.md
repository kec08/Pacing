# #213 러닝 종료 화면·활동 상세 평균 페이스 정합성 최종 보고서

## 상태

개발 완료 · 실기기 러닝 QA 제한 확인

## 관련 이슈

- https://github.com/kec08/Pacing/issues/213
- 브랜치: `fix/213-running-summary-detail-average-pace`

## 구현 내용

- 종료 화면의 평균 페이스를 경과 시간이 아닌 유효 GPS 이동 구간의 누적 시간 기준으로 변경했다.
- 종료 음성 안내도 종료 화면·활동 상세와 같은 평균 페이스 값을 사용하도록 통일했다.
- 평균 페이스 정책의 입력 이름을 `movingElapsedSeconds`로 명시해, 경과 시간과 이동 시간의 혼용을 방지했다.
- 종료 화면과 저장 기록이 동일한 이동 시간·거리에서 같은 평균 페이스를 표시하는 회귀 테스트를 추가했다.

## 수치 검증

첨부된 1~5km 구간 페이스의 합계는 다음과 같다.

| 구간 | 페이스 |
| --- | --- |
| 1km | 4'14\" |
| 2km | 4'45\" |
| 3km | 4'21\" |
| 4km | 4'46\" |
| 5km | 4'39\" |
| **평균** | **4'33\"** |

5개 구간의 합계는 1,365초이며, `1,365초 ÷ 5km = 273초/km = 4'33\"/km`이다. 활동 상세와 같은 기준으로 종료 화면도 `4'33\"`을 표시한다.
