## 구현 요약

러닝 측정 시간이 `Timer` 의존으로만 계산되던 구조를 보완해, 화면이 꺼지거나 앱이 백그라운드로 전환된 뒤 복귀해도 실제 경과 시간이 맞게 반영되도록 수정했다.  
또한 백그라운드에서 묶음으로 전달되는 위치 업데이트를 마지막 좌표 하나만 쓰지 않고 모두 반영하도록 바꿔, 앱 복귀 후에도 이동 경로 마커가 끊기지 않도록 보강했다.  
추가로 러닝 종료 요약 화면의 통계 카드에서 칼로리 값이 줄바꿈되지 않도록 정리하고, `평균 페이스` 문구 아래에 1km 단위 랩 평균 페이스 목록이 표시되도록 개선했다.

## 구현된 기능 목록

- [x] 러닝 경과 시간을 `Date` 기준으로 계산하도록 변경
- [x] 백그라운드 위치 배치 전체를 경로 및 거리 계산에 반영
- [x] 완료된 1km 랩별 평균 페이스를 ViewModel에서 누적 저장
- [x] 종료 요약 화면에 `평균 페이스` 섹션 추가
- [x] `1km`, `2km`, `3km` 등 km별 평균 페이스 행 표시
- [x] 칼로리 값 1줄 표시를 위한 축소 대응 추가
- [x] 백그라운드 모드 설정 형식 점검 및 정리

## 계획서 대비 변경 사항

| 항목 | 계획 | 실제 구현 | 사유 |
|------|------|-----------|------|
| 백그라운드 측정 유지 | 설정 점검 및 보강 | `Timer` 중심 시간을 `Date` 기준 계산으로 전환 | 화면 잠금 시 시간 누락 가능성이 더 핵심 원인으로 판단됨 |
| 백그라운드 경로 유지 | 위치 기록 흐름 보강 | 위치 배치 전체를 경로와 거리 계산에 반영 | 백그라운드에서는 중간 좌표가 묶음으로 전달될 수 있기 때문 |
| km별 페이스 표시 | 요약 화면에 목록 추가 | ViewModel에서 랩 결과를 저장 후 요약 화면에 전달 | 종료 후에도 km별 평균 페이스를 안정적으로 재사용하기 위함 |
| 칼로리 표시 정리 | 1줄 표시 | `lineLimit` + `minimumScaleFactor` 적용 | 기기 폭이 좁아도 줄바꿈 방지 목적 |

## 알려진 제한사항

- 현재 km별 평균 페이스 목록은 완료된 1km 랩만 표시하며, 마지막 1km 미만 잔여 구간은 포함하지 않는다.
- 실기기에서 `Always` 위치 권한 허용 여부와 화면 잠금 상태의 실제 기록 지속성은 별도 확인이 필요하다.
- 이 환경에서는 `xcode-select` 가 Xcode 앱이 아닌 Command Line Tools를 가리켜 빌드까지 끝까지 확인하지 못했다.
