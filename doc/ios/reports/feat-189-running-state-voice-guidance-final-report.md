# #189 iPhone 러닝 상태 음성 안내 및 카운트다운 UX 최종 보고서

## 개요

iPhone 러닝에서 화면을 보지 않아도 시작·일시정지·재개 상태를 알 수 있도록 한국어 음성 안내를 추가했다. 함께 러닝 제어와 카운트다운의 시각적 피드백을 다듬어, 상태 전환을 더 빠르게 인지할 수 있도록 개선했다.

## 변경 사항

- 카운트다운 완료 후 러닝 기록이 실제 시작될 때 “운동을 시작합니다.”를 안내한다.
- 실행 중 일시정지하면 진행 중인 랩 안내를 중지한 뒤 “운동을 정지합니다.”를 안내한다.
- 재개 버튼을 눌러 러닝을 다시 시작하면 “운동을 재개합니다.”를 안내한다.
- 기존 1km 랩 음성 안내와 한국어 시스템 음성 선택, Bluetooth 출력, 음악 ducking 처리를 그대로 유지했다.
- 음성 안내 추상화를 `RunningVoiceAnnouncing`으로 확장해 랩 안내와 상태 안내가 같은 오디오 세션 정책을 사용하도록 정리했다.
- 일시정지 상태 컨트롤을 `종료(왼쪽) → 재개(오른쪽)` 순서로 배치했다.
- 러닝 중 상단 지표(km·BPM·페이스 등)를 탭할 때의 페이드·축소 전환을 제거해 즉시 변경되도록 했다.
- 카운트다운 `3 → 2 → 1`은 기본 크기의 84%에서 172pt까지 부드럽게 확대되도록 적용했다.
- 카운트다운 중에는 전체 화면을 덮는 불투명 검정 배경을 표시해 숫자에 집중할 수 있게 했다.

## 기술적 고려 사항

- View는 버튼 배치와 시각적 표현만 담당하고, 실제 러닝 상태 전환 및 음성 요청은 `RunningViewModel`에 둬 Watch 명령과 iPhone 버튼 흐름이 같은 정책을 사용한다.
- 상태 안내와 랩 안내는 동일한 `AVSpeechSynthesizer` 및 `AVAudioSession`을 사용하므로, 일시정지 안내 전에는 기존 랩 안내를 즉시 중단한다.
- 카운트다운 숫자의 확대는 스프링 반동 대신 `easeOut` 애니메이션을 사용해 숫자마다 일관된 움직임을 유지한다.
