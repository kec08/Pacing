# #154 러닝 고도 상승 GPS 노이즈 과대 누적 보정 최종 보고서

## 개요

GPS 수직 오차가 반복 누적돼 동일 러닝에서 Nike Run의 16m 대비 Pacing이 109m를 표시한 문제를 보정했다. 고도 상승을 개별 GPS 변화량으로 즉시 합산하지 않고, 유효한 수직 정확도와 충분한 고도 변화가 확인된 구간만 반영하도록 변경했다.

## 변경 사항

- 수직 정확도 허용 기준을 10m 이하에서 5m 이하로 강화했다.
- 5개 샘플 중앙값 처리 후, 12m 이상 상승하고 8m 이상 하강해 구간이 확정된 경우에만 상승 고도를 누적한다.
- 종료 전까지 계속 상승하는 경로도 동일한 확정 기준으로 반영한다.
- `pause → resume` 시 기존 고도 샘플을 초기화하지 않아 전체 러닝 세션의 상승 고도가 유지된다.
- 평지성 진동, 반복 GPS 상승/하강, 지속 상승을 포함한 회귀 테스트를 추가했다.

## 기술적 고려 사항

- ViewModel은 고도 위치 샘플 수집과 화면 상태만 관리하며, 필터링·누적은 순수 계산 함수인 `RunMetricsCalculator`에 유지했다.
- Firebase 저장, 종료 요약, 러닝 중 표시는 동일한 `elevationGain` 계산 결과를 사용한다.
- 이번 변경은 외부 지도 고도(DEM)나 기압계 전용 데이터 없이 Core Location 고도 노이즈를 억제하는 범위다. Nike Run과 절대적으로 동일한 값은 보장하지 않는다.

## 남은 이슈

실기기 GPS 환경의 수직 정확도 분포와 실제 고도값을 아직 확보하지 못했다. PR 검토 후 실기기 비교에서 실제 상승이 과도하게 제거되거나 여전히 과대 누적되면, 기록된 위치 샘플을 기준으로 임계값을 재조정한다.
