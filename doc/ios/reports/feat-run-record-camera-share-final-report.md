# 러닝 기록 카메라 공유 최종 보고서

## 작업 정보

- 이슈: #218
- 브랜치: `feat/218-run-record-camera-share`
- PR: #219

## 완료 사항

- 활동 상세 화면 우측 상단에 러닝 기록 공유 진입 버튼을 추가했습니다.
- 거리, 기록, 경로 3가지 양식을 선택할 수 있도록 구성했습니다.
- 각 양식은 Pacing 로고와 러닝 기록을 투명한 흰색 오버레이로 사진에 합성합니다.
- 카메라 권한 안내, 촬영, 재촬영, 시스템 공유 흐름을 구현했습니다.
- 결과 미리보기는 실시간 카메라 화면과 같은 비율·레이아웃으로 표시합니다.
- 일반 공유에는 화면 비율 공유 이미지를 전달하고, Instagram 활동 선택 시에는 1080×1920 스토리 비율 이미지를 전달합니다.
- 경로 양식은 `거리 → 경로 → 위치` 순서로 표시하며, 위치 좌표를 도시·국가 형태로 변환합니다.

## 주요 구현 사항

- `RunActivityDetailView`에 공유 진입점을 추가했습니다.
- `RunRecordCameraShareView`에서 양식 선택, 카메라 세션, 촬영 결과, 이미지 합성, 시스템 공유를 담당합니다.
- 촬영 결과 화면과 실제 공유 파일의 오버레이 레이아웃을 분리해 결과 화면의 카메라 일치성을 유지합니다.
- 공유 시점에 일반 비율과 Instagram 스토리 비율 이미지를 준비해 첫 공유에도 이미지가 누락되지 않도록 보완했습니다.
- 카메라 촬영은 속도 우선 설정과 중복 촬영 방지 상태를 적용했습니다.

- 일반 공유 대상에서 화면 비율 이미지가 전달되는지 확인
- Instagram 공유 확장에서 1080×1920 스토리 이미지가 전달되는지 확인
- 역지오코딩 성공·실패 시 위치명 표기 확인
- 다양한 기기 화면에서 X 버튼과 하단 버튼의 터치 영역 확인
