## 구현 요약

내 프로필에서 공개 범위를 설정하고, 설정에 따라 친구 검색·추천·프로필 상세 활동 데이터 접근을 제한했다. 비공개 상태에서도 사진·이름·상태·친구 버튼은 유지하고, 상세 데이터 대신 비공개 안내를 표시한다. 로그인 화면의 다크 모드 대비와 Apple·이메일 로그인 전환 화면도 안정화했다.

## 구현된 기능 목록

- [x] 내 프로필 우측 상단 공개 설정 버튼 및 `전체 공개`·`친구만 공개`·`비공개` 선택 화면
- [x] 라디오 선택 UI와 다크 모드 대응 디자인
- [x] Firestore `profileVisibility`, `profileVisibilityUpdatedAt` 저장
- [x] Callable Function 기반 검색·추천·프로필 상세 공개 범위 검증
- [x] 클라이언트 `users` 목록 조회 차단 및 활동 데이터 규칙 연동
- [x] 비공개 프로필의 기본 정보·친구 버튼 유지 및 잠금 안내 UI
- [x] 프로필 편집 다크 모드 입력 카드 대비 개선
- [x] Google 로그인 버튼 텍스트 대비 및 로그인 배경 개선
- [x] Apple 로그인 버튼 전체 폭·iPhone 세로 화면 고정
- [x] 이메일 로그인 중 기존 로그인 화면 로딩 상태 유지
- [x] 체중 기반 칼로리 계산을 위해 키·몸무게 입력·저장 유지

## 계획서 대비 변경 사항

| 항목 | 계획 | 실제 구현 | 사유 |
|---|---|---|---|
| 키·몸무게 | 온보딩·프로필 편집에서 제거 | 기존 입력·저장 유지 | 체중 기반 칼로리 계산에 필요하다는 개발자 검토 반영 |
