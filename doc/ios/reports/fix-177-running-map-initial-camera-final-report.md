## 개요

러닝 탭 최초 진입 시 지도 카메라가 과도하게 확대되는 문제를 수정했다. 최초 위치와 지도 뷰 준비 시점의 순서 경쟁을 제거하고, 내 위치 버튼과 동일한 1,000m 거리로 첫 카메라를 한 번만 설정한다.

## 원인

기존 구현은 MapKit의 `.automatic` 초기 카메라가 `onMapCameraChange`를 통해 `mapZoomDistance`를 작은 값으로 바꿀 수 있는 상태에서, 첫 위치 수신이 그 값을 사용해 카메라를 보정했다.

또한 위치 콜백이 지도 뷰 준비보다 먼저 발생하면 최초 카메라 설정 시점이 불안정했다.

```text
위치 수신 또는 자동 카메라 콜백 순서 경쟁
→ mapZoomDistance가 작은 값으로 갱신될 수 있음
→ 첫 카메라 보정도 작은 거리 사용
→ 지도 과확대
```

## 변경 사항

- 최초 위치 좌표를 지도 뷰가 준비될 때까지 보관한다.
- 지도 뷰 준비 후 해당 좌표를 중심으로 1,000m 카메라를 직접 설정한다.
- 초기 설정이 완료될 때까지 `.automatic` 카메라 콜백이 줌 거리와 자동 추적 상태를 변경하지 못하게 한다.
- 최초 진입 카메라 거리 정책 단위 테스트를 추가했다.
- 실기기 테스트를 위해 동일 수정 커밋 `0be5fd2`를 `feat/173-watch-music-playback`에도 반영했다.
