# #227 러닝 거리·페이스·음성 안내 QA 보고

## 확인한 코드 결함과 수정
- Watch 누적 거리가 수신되면 iPhone GPS 누적 거리를 표시·저장에 반영하지 않아, 작은 Watch 값이 정상적인 iPhone 기록을 덮을 수 있었다. 같은 운동의 두 거리 중 큰 누적값을 사용하도록 수정했다.
- Watch HealthKit 세션 실패 후 화면 타이머는 계속 돌아 거리만 멈추고 평균 페이스가 커질 수 있었다. 측정 중단을 표시하고 오류를 기록하도록 수정했다.
- 현재 페이스가 1km 전 평균값으로 대체돼 거리 갱신 지연 때 비정상적인 수치를 표시했다. iPhone은 최근 승인 GPS 구간, Watch는 자체 운동 거리 변화로 현재 페이스를 계산한다. iPhone 화면에는 현재·평균 페이스를 나란히 표시한다.
- MeloTTS 재생용 `.playback` 오디오 세션에 통화용 Bluetooth 옵션이 포함되어 있었다. 해당 옵션을 제거하고 오디오 세션 설정 실패 로그를 추가했다.

## 수행한 확인
- 수정 범위와 호출 경로를 정적으로 검토했다.
- `git diff --check`와 Xcode 프로젝트 설정 파일의 `plutil -lint`를 통과했다.
- 사용자 요청에 따라 빌드, 자동 테스트, 실기기 러닝은 실행하지 않았다.

## 실기기에서 남은 확인
1. `feat/227-running-background-distance`의 iPhone·Watch 앱을 함께 설치하고 Xcode 프로젝트 경로를 기록한다. 현재 관찰 가능한 Pacing Xcode 창은 `feat/222-melotts-offline`을 보고 있다.
2. 새 러닝의 날짜, 잠금 직전·잠금 중·종료 시 iPhone GPS 거리, Watch 거리, 현재·평균 페이스를 비교한다.
3. 시작·1km·종료 음성이 MeloTTS인지 확인하고 기계음이 나오면 Xcode 콘솔의 `MeloTTS`, `음성 안내 오디오 세션 설정 실패`, `Watch 운동 세션 실패`, `위치 측정 실패` 로그를 확보한다.
4. 첨부 화면은 10월 26일 기록을 표시하지만 사용자는 새 러닝이라고 답했다. 두 기록이 같은 것인지 날짜와 설치 브랜치를 대조한다.

실기기 결과가 없으므로 21km 완주 시 거리 정확도와 MeloTTS 재생 성공은 아직 확정할 수 없다.
