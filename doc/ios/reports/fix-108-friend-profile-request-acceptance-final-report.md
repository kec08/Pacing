## 구현 요약

친구 프로필의 공개 정보와 친구 전용 활동 데이터를 분리해 비친구 진입 시 권한 오류를 제거했다. 친구 요청 수락은 클라이언트 중복 입력을 방지하고 서버가 동일 요청을 멱등 처리하도록 개선했다.

## 구현된 기능 목록

- [x] 비친구 프로필에서 친구 전용 활동 조회를 방지
- [x] 비친구 활동 영역의 잠금 안내 상태 제공
- [x] 친구 요청 수락 중복 탭 방지 및 진행 상태 표시
- [x] 이미 수락된 요청의 서버 멱등 성공 처리
- [x] Callable 응답 성공 여부 검증
- [x] 취소된 친구 요청의 상태 초기화 및 재전송 지원
- [x] 요청 대기 러너의 검색 결과 유지 및 추천 목록 필터 분리
- [x] 검색·추천 빈 상태 UI 간소화
- [x] 입력 변경 기반 자동 검색 및 친구 우선 결과 정렬
- [x] 친구 상태의 메인 핑크 텍스트·아이콘·테두리 강조
- [x] 친구 목록 행 전체 프로필 이동 지원
- [x] `acceptFriendRequest` Cloud Function 운영 배포

## 계획서 대비 변경 사항

| 항목 | 계획 | 실제 구현 | 사유 |
|------|------|-----------|------|
| 수락 실패 원인 확인 | 서버·클라이언트 흐름 점검 | 동일 요청의 반복 Callable 수신 및 `pending` 전용 처리 확인 | 실제 로그 기반으로 중복 호출 방어를 추가 |
| 수락 결과 검증 | 응답과 관계 확인 | Callable 응답의 `accepted` 값 검증 | 잘못된 서버 응답을 성공으로 표시하지 않기 위함 |
