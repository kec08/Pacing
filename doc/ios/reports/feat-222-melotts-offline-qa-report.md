# MeloTTS 오프라인 음성 안내 QA 보고서

## 상태

iPhone 앱 연결 및 시뮬레이터 음성 데이터 생성 확인. 실기기 청취와 성능 QA 대기.

## 관련 작업

- 이슈: [#222](https://github.com/kec08/Pacing/issues/222)
- 브랜치: `feat/222-melotts-offline` (`dev`의 PR #223 머지 커밋 기준)
- PR: 아직 생성하지 않음

## 변경 사항

- iPhone 타깃에 Microsoft ONNX Runtime Swift Package 1.24.2를 추가했다.
- [MeloTTS 한국어 ONNX 변환본](https://huggingface.co/gnyong/melotts-kr-onnx/tree/main)의 INT8 모델과 MIT 라이선스·출처를 앱에 포함했다. 모델 SHA-256은 `421b94ce7e803fdd0126c7d39d90192b64878794619668cf3ec12611fc860f88`이다.
- 러닝 상태, 1km 랩, 종료 문장의 한국어 발음 사전을 g2pkk로 생성해 번들에 포함했다. 숫자와 단위를 토큰으로 조립하므로 기기에서 Python이나 인터넷이 필요하지 않다.
- 모델은 러닝 화면에서 비동기로 준비하며 추론은 별도 큐에서 실행한다. 미준비·지원하지 않는 값·추론 실패·1.2초 초과 시 기존 `AVSpeechSynthesizer`로 대체해 안내를 계속한다.
- MeloTTS WAV와 기존 음성 모두 동일한 `AVAudioSession` 음악 ducking 및 안내 큐를 사용한다.

## 실기기 QA

- [ ] 러닝 시작, 일시정지, 재개, 종료 안내가 한국어로 자연스럽게 들린다.
- [ ] 1km, 2km, 3km 안내가 각각 빠짐없이 나오고 거리·시간·페이스 숫자를 정확히 읽는다.
- [ ] 모델 준비 전 또는 추론 지연 시 시스템 음성으로 대체되어 안내가 누락되지 않는다. 콘솔의 `MeloTTS inference`와 대체 로그를 확인한다.
- [ ] Apple Music과 Bluetooth 이어폰에서 안내 중 곡은 계속 재생되고 음량이 낮아졌다가 복원된다.
- [ ] 화면 잠금·백그라운드·Watch 연결 상태에서 안내 순서와 러닝 거리 측정이 유지된다.
- [ ] 앱 크기, 첫 모델 로딩 시간, 메모리, 연속 안내의 발화 시작 지연을 기록한다.

## 제한

- 모델 파일만 약 53.5 MB이며 ONNX Runtime이 앱 크기와 메모리를 추가로 사용한다.
- iOS 26 Simulator의 모델 로딩을 포함한 1km 합성 테스트 한 건은 약 12.6초였다. 첫 로딩과 추론을 분리한 실기기 측정이 필요하다.
- 한국어 발음 사전은 러닝 안내의 숫자·단위 범위에 맞춰 생성했다. 지원 범위를 벗어나면 시스템 음성으로 대체한다.
- iPhone 실기기에서 MeloTTS 출력의 발음·속도·이어폰 라우팅은 아직 확인되지 않았다. 시뮬레이터 WAV 생성만으로 실기기 품질을 보장할 수 없다.
- 음성 합성은 iPhone에서 수행한다. Watch 앱 자체에는 별도 MeloTTS 추론 엔진을 넣지 않았다.
# 최종 확인 (2026-10-23)

- 시작·일시정지·재개 MeloTTS 음성 클립을 앱 번들에서 확인하고 iOS 시뮬레이터 디코딩 테스트를 통과했다.
- iOS/Watch 시뮬레이터 `build-for-testing` 및 iPhone arm64 Debug 빌드가 통과했다.
- 오프라인 한국어 토큰 변환과 실제 ONNX 1km 안내 음성 생성 테스트 2개가 통과했다.
- 실기기에서 음질, Bluetooth 출력, 음악 볼륨 감소·복원, 백그라운드 재생과 첫 발화 지연은 개발자 QA가 필요하다.
## 실기기 발음 오류 후속 QA (2026-10-23)

- 원인: 저장소의 `symbols.json`과 ONNX 체크포인트 설정의 한국어 음소 ID가 2칸 달라 잘못된 음소가 입력됐다.
- 모델 설정 순서로 발음 사전을 재생성하고 고정 상태 안내 음성 3개를 다시 생성했다.
- 숫자 발음 입력을 `1=일`, `2=이`, `9=구`, `10=십`, `20=이십`으로 확인했다.
- 수정된 1km 안내 샘플의 오프라인 합성과 iPhone arm64 Debug 빌드가 성공했다.
- 한국어 청취 품질과 실제 iPhone·Watch 안내 출력은 개발자 실기기 QA가 필요하다.
## 음성 톤·문장 개선 확인 (2026-10-23)

- 러닝 상태, 1km 구간, 종료 안내 문구와 대응 발음 사전·고정 음성 파일을 함께 갱신했다.
- MeloTTS 44.1 kHz 합성 샘플을 48 kHz로 재생하도록 설정해 속도와 음높이를 약 9% 올렸다. 시스템 음성 대체 경로도 속도·피치를 소폭 높였다.
- iPhone arm64 Debug 빌드 통과. 실기기에서 자연스러운 음질과 음악 덕킹은 청취 확인이 필요하다.

## 안내 멘트 복원 및 종료 음성 후속 수정 (2026-10-23)

- 시작 안내는 “러닝을 시작합니다”로, 정지·재개·1km·종료 안내는 이전의 간결한 기록 문구로 복원했다. 발음 사전과 고정 음성 파일 3개도 다시 생성했다.
- MeloTTS 재생 속도를 0.92배, 시스템 음성 대체 속도를 0.48로 낮췄다. 48 kHz 재생으로 높아진 음높이는 유지한다.
- 종료 멘트도 1km와 동일한 1.2초 추론 제한을 적용받아 시스템 음성으로 바뀔 수 있었다. 종료 멘트에만 최대 15초를 허용하도록 변경했다.
- 종료 음성의 실제 합성 시간, 말소리, 음악 음량 복원은 iPhone 실기기에서 확인해야 한다. 15초를 넘거나 모델 합성이 실패하면 안내 누락 방지를 위해 시스템 한국어 음성으로 대체된다.

## 종료 즉시 재생 및 음질 후속 QA (2026-10-23)

- 원인: 종료 문장 전체의 ONNX 합성이 끝날 때까지 아무 안내도 재생하지 않았고, 제한 시간을 넘으면 시스템 음성으로 대체했다.
- “운동을 완료했습니다”를 MeloTTS 고정 클립으로 추가했다. 종료 직후 클립을 재생하는 동안 현재 거리·시간·페이스 문장을 합성하고, 음악 ducking은 두 문장 사이에도 유지한다.
- 발화 길이를 모델에서 조정하고 플레이어의 속도 가공을 제거했다. 출력의 고음역을 약하게 보정하고 시스템 대체 음성의 톤을 높였다.
- iPhone arm64 Debug 빌드와 앱 번들의 종료 클립 포함을 확인했다. 거리·시간·페이스가 들어간 종료 문구의 오프라인 사전 키도 확인했다.
- 시뮬레이터 테스트는 기기 부팅 단계가 진행되지 않아 중단했다. 실제 종료 직후 재생 지연, 한국어 발음, Bluetooth 출력, 음악 음량 복원은 실기기 확인이 필요하다.

## 음성 속도 미세 조정 (2026-10-23)

- MeloTTS 발화 길이 설정을 1.08에서 1.04로 낮춰 약 4% 빠르게 했다. 고정 안내 클립 4개도 같은 설정으로 다시 생성했다.
- 문구·음높이·음악 음량 처리에는 변경이 없다. 실제 청취 속도는 iPhone에서 확인한다.

## 종료 브리핑 누락 및 시작·종료 발음 후속 QA (2026-10-23)

- 요약 화면 저장·취소 직후 `reset()`이 음성 서비스를 중단해 첫 문장 뒤 거리·시간·평균 페이스가 누락될 수 있었다. 초기화에서 음성 중단을 제거하고, 새 러닝 시작 시 이전 안내를 중단하도록 옮겼다.
- 러닝 화면이 닫혀도 완료 브리핑이 재생되도록 앱에서 음성 서비스 인스턴스를 공유한다.
- “이제 러닝을 시작합니다”로 도입을 다듬고, 문장 전체에 일괄 적용하던 발음 변환을 단어별로 바꿔 시작·종료 음성 클립을 재생성했다.
- 실기기에서 완료 후 곧바로 저장하거나 화면을 닫아도 거리·시간·평균 페이스가 끝까지 들리는지, 시작·종료 발음이 자연스러운지 확인해야 한다.
- iPhone arm64 Debug 빌드 및 iOS 시뮬레이터 테스트 빌드가 통과했다. `testResetKeepsFinishBriefingPlaying`, `testMeloLexiconCoversRunningAnnouncementsOffline` 2건도 통과했다.
## 시작 멘트와 종료 요약 지연 수정 (2026-10-23)
- 시작 멘트를 “러닝을 시작합니다.”로 맞추고 한국어 발음 사전과 시작 MeloTTS 클립을 다시 생성했다.
- 종료 요약은 거리 문장과 시간·페이스 문장으로 나눠 순서대로 미리 합성한다. 거리 문장은 고정 종료 멘트가 재생되는 동안 생성해 이어서 재생한다.
- iOS 기기 대상 서명 없는 빌드 통과, `git diff --check` 통과. 실제 안내 간격과 발음은 실기기에서 확인이 필요하다.

## 시작 문구 및 MeloTTS 종료 안내 수정 (2026-10-23)
- 시작 안내를 “운동을 시작합니다.”로 바꾸고 발음 사전과 시작 클립을 다시 생성했다.
- 종료 요약 분할 후 빠진 “총 시간” 발음 항목을 추가했다. 1km 안내의 1.2초 합성 제한은 15초로 조정하고, 모델 로딩 중에도 합성 작업을 대기열에 넣어 정상적인 MeloTTS 추론이 진행 중일 때 시스템 음성으로 전환되지 않도록 했다.
- iOS 기기 대상 서명 없는 빌드는 통과했다. 시뮬레이터 회귀 테스트는 사용자의 요청에 따라 중단했다. 종료 멘트와 거리·시간·페이스 안내의 실제 간격 및 기기별 추론 시간을 실기기 확인 항목으로 남겼다.
- 개발자가 실기기에서 최종 음성 안내가 정상 동작한다고 확인했다(2026-10-23). 기기 모델과 측정된 안내 간격은 기록되지 않았다.
