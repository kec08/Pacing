## 구현 완료 사항

- 온보딩의 나이 Picker와 관련 상태를 제거했다.
- 프로필 편집 화면의 나이 입력, 검증, 오류 문구를 제거했다.
- `UserDefaults`의 나이 읽기·쓰기 경로를 제거하고, 기존 로컬 `age` 키는 정리한다.
- Firestore 프로필 저장 API에서 나이 파라미터를 제거했다.
- 프로필 저장 시 기존 Firestore `age` 필드를 삭제한다.
- 재로그인 중 프로필을 복원할 때 기존 Firestore `age` 필드를 삭제한다.

## 알려진 제한사항

- 기존 Firestore `age` 필드는 사용자가 재로그인하거나 프로필을 저장한 뒤 삭제된다. 장기간 비활성 계정의 필드를 즉시 일괄 삭제하는 서버 마이그레이션은 포함하지 않았다.
- 실제 기기에서 신규 가입과 기존 계정 재로그인 시나리오는 심사 재제출 전 수동 확인이 권장된다.
