# 러닝 종료 화면·활동 상세 평균 페이스 정합성 수정 계획서

> **상태**: 완료  
> **작성일**: 2026-10-02  
> **관련 이슈**: [#213](https://github.com/kec08/Pacing/issues/213)  
> **브랜치**: `fix/213-running-summary-detail-average-pace`

---

## 1. 목적 및 배경

동일한 5.10km 러닝에서 종료 화면은 평균 페이스를 `5'02\"`로, 활동 상세 화면은 `4'33\"`로 표시했다. 종료 화면에서도 활동 상세와 같은 전체 유효 이동 구간 기준 평균 페이스를 표시하도록 정합성을 맞춘다.

## 2. 조사 결과

- 종료 화면은 `elapsedSeconds ÷ distance`를 사용했다.
- 활동 상세는 저장된 `movingDuration ÷ distance`를 우선 사용했다.
- 두 화면이 다른 시간 원천을 사용해 동일 러닝의 평균 페이스가 불일치했다.

## 3. 구현 방향

- [x] 유효 GPS 이동 구간의 누적 시간 ÷ 총 거리를 표시 평균 페이스의 단일 기준으로 사용한다.
- [x] 종료 화면과 완료 음성이 활동 상세와 같은 `avgPace` 경로를 사용하게 한다.
- [x] 이동 시간·거리·반올림 규칙이 종료 화면과 저장 기록에서 일치하는지 회귀 테스트로 검증한다.

## 4. 완료 기준

- [x] 동일 러닝의 종료 화면과 활동 상세 평균 페이스가 일치한다.
- [x] 마지막 km 랩 또는 경과 시간이 아닌 전체 유효 이동 구간 기준 평균 페이스를 표시한다.
- [x] km별 랩 페이스와 현재 페이스 동작을 변경하지 않는다.
- [x] 코드 정적 검증과 iPhone Debug 빌드를 통과한다.

## 5. 검증 제한

- 사용 가능한 iOS Simulator 런타임이 없어 단위 테스트 실행은 하지 못했다.
- 실제 GPS 이동과 일시정지·재개를 포함한 실기기 러닝 QA는 추후 수행한다.
