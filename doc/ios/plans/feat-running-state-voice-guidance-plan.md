## 1. 목적 및 배경

현재 iPhone 러닝은 1km를 완료했을 때만 음성으로 거리·시간·평균 페이스를 안내한다. 사용자가 화면을 보지 않는 상황에서도 러닝 상태 전환을 즉시 알 수 있도록 카운트다운 완료 후 시작, 일시정지, 재개 시 한국어 음성 안내를 제공한다.

## 2. 사용자 시나리오

1. 사용자가 러닝 시작을 누르고 3초 카운트다운이 끝난다.
2. 러닝 기록이 시작되며 “운동을 시작합니다.”를 한 번 안내한다.
3. 사용자가 일시정지하면 진행 중인 랩 안내를 중지하고 “운동을 정지합니다.”를 안내한다.
4. 사용자가 재개하면 “운동을 재개합니다.”를 안내한다.
5. Watch에서 전달된 시작·정지·재개 명령도 iPhone 상태 전환 함수가 동일하므로 같은 안내 정책을 적용한다.

## 3. 현재 구조 및 구현 방향

- `LapVoiceAnnouncementService`는 `AVSpeechSynthesizer`, 한국어 음성 선택, Bluetooth·음악 ducking을 이미 처리한다.
- 현재 프로토콜은 km 랩 전용 모델만 받으므로, 일반 문구도 전달할 수 있게 음성 안내 추상화를 확장한다.
- `RunningViewModel`의 `start`, `pause`, `resume`에서 상태가 실제 전환된 뒤 안내를 요청한다. View는 버튼 이벤트 전달에만 집중한다.
- 일시정지 시 기존 랩 안내를 즉시 중지한 뒤 정지 안내를 재생한다.
- 카운트다운 숫자 자체와 종료 안내는 이번 범위에서 제외한다.
