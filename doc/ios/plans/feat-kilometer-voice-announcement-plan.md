# 1km 음성 안내 계획서

## 1. 목적

러닝 중 1km 경계를 통과할 때마다 NRC와 유사하게 아래 순서로 한국어 음성 안내를 제공한다.

> “1킬로미터. 시간 5분 46초. 평균 페이스 5분 46초.”

안내 값은 경계 통과 시점의 **누적 러닝 시간**과 **전체 거리 기준 평균 페이스**를 사용한다. 일시정지 시간은 포함하지 않는다.

## 2. 현재 구조 확인

- `RunningViewModel.completePendingLapsIfNeeded()`가 `distance >= nextLapDistanceMark`에서 1km 랩을 확정하고 `RunLapPace`를 저장한다.
- 랩별 페이스와 현재 평균 페이스 계산은 존재하지만, `AVSpeechSynthesizer` 기반 음성 출력 계층은 없다.
- Apple Music 재생 중에도 러닝이 가능하므로, 안내 음성은 다른 오디오를 잠시 낮추고(ducking) 완료 후 정상 복귀해야 한다.

## 3. 구현 계획

### Task 1. 음성 안내 추상화

- `LapVoiceAnnouncing` 프로토콜과 `AVSpeechSynthesizer` 구현체를 추가한다.
- ViewModel에는 프로토콜만 주입해 단위 테스트에서 실제 음성 재생 없이 호출 내용·횟수를 검증한다.
- 음성 안내 중복 방지와 러닝 종료/리셋 시 진행 중인 안내 취소를 제공한다.

### Task 2. 안내 문구 및 오디오 세션

- 경계 통과 직후 `km → 누적 시간 → 평균 페이스` 순서의 한국어 문구를 생성한다.
- 시간은 `분/초`, 평균 페이스는 `분/초 per km` 형식으로 읽는다.
- `AVAudioSession`의 ducking 옵션을 사용해 음악을 중단하지 않고 안내가 들리게 한다.
- 평균 페이스를 계산할 수 없는 비정상 거리·시간은 음성 안내를 생략한다.

### Task 3. 경계·상태 정합성

- 한 위치 업데이트에서 여러 km 경계를 넘더라도 각 km를 한 번씩 순서대로 안내한다.
- pause/resume 동안에는 안내가 발생하지 않으며, 재개 후 중복 안내가 없다.
- 화면의 랩 저장값, 안내에 쓰이는 경계 거리·시간, 기존 페이스 계산 기준을 일치시킨다.

### Task 4. 검증

- 1km·다중 km 경계·pause/resume·평균 페이스 불가 케이스의 단위 테스트를 추가한다.
- 시뮬레이터에서 문구 생성·안내 호출 순서를 검증한다.
- 실기기에서 무음/음악 재생/블루투스 이어폰 환경의 음량 ducking과 안내 청취성을 QA한다.

## 4. 완료 기준

- 매 완주 1km마다 “km, 누적 시간, 평균 페이스” 순서로 한 번만 음성 안내된다.
- 일시정지 시간은 시간과 평균 페이스에 포함되지 않는다.
- 다중 km 이동과 pause/resume에도 안내 누락·중복이 없다.
- 음악 재생을 끊지 않고 음성 안내가 들린다.
- 단위 테스트 및 실기기 오디오 QA 결과가 기록된다.

## 5. 이슈 초안

**제목:** `[feat] 1km 구간 음성 안내 추가`

**라벨:** `feature`

**본문:** 러닝 중 매 1km 경계에서 km, 누적 시간, 전체 평균 페이스를 한국어 음성으로 안내한다. 기존 1km 랩 계산과 동일한 경계 기준을 사용하고, 음악 재생 중에는 ducking으로 안내한다.
