## 1. 목적 및 배경

현재 마이 탭은 상단 헤더에서 프로필 이미지, 닉네임, 활동 상태만 짧게 보여주고 있으며, 상세 프로필 확인과 수정 흐름은 설정 리스트의 `프로필 수정` 항목으로 분리되어 있다.
이 구조는 사용자가 자신의 프로필을 보는 흐름과 수정하는 흐름이 분리되어 있어 자연스럽지 않고, 친구 탭의 프로필 상세 화면과도 경험이 맞지 않는다.

이번 기능에서는 마이 탭 좌상단 프로필 이미지/이름 영역을 탭하면 친구 프로필과 유사한 형태의 `내 프로필 상세 화면`으로 진입하도록 바꾼다.
또한 프로필 수정은 설정 메뉴가 아니라 상세 프로필 화면 안에서 바로 이어지도록 재구성해, 인스타그램의 `프로필 보기 → 프로필 편집`과 유사한 흐름으로 정리한다.

## 2. 사용자 시나리오

```
사용자가 마이 탭에 진입하면
→ 좌상단의 프로필 이미지 또는 닉네임 영역을 탭하고
→ 친구 프로필과 유사한 형태의 내 프로필 상세 화면으로 이동한다
→ 내 프로필 상세에서 프로필 이미지, 닉네임, 활동 상태, 러닝 요약 지표, 최근 들은 노래를 확인한다
→ 상세 화면의 `프로필 편집` 버튼을 탭하고
→ 인스타그램식 편집 흐름의 화면에서 사진/닉네임/기본 신체 정보를 수정한다
→ 저장 후 상세 화면과 마이 탭 상단 헤더에 변경 사항이 즉시 반영된다
```

## 3. 화면 구성

### 주요 화면
- 마이 탭 메인: 좌상단 프로필 이미지/닉네임 영역 탭 가능하도록 수정
- 내 프로필 상세: 친구 프로필 스타일 기반의 본인 전용 상세 화면
- 프로필 편집 화면: 인스타그램식 정보 편집 중심 UI

### UI 요소
- 마이 탭 프로필 헤더
  - 프로필 이미지
  - 닉네임
  - 활동 상태 텍스트
  - 상세 진입 affordance
- 내 프로필 상세 화면
  - 상단 뒤로가기 + 화면 제목
  - 중앙 프로필 아바타
  - 닉네임 / 활동 상태
  - `프로필 편집` 메인 버튼
  - 누적 거리 / 운동 시간 / 평균 페이스 요약
  - 최근 들은 노래 섹션
  - 빈 상태 / 로딩 상태 / 에러 상태
- 프로필 편집 화면
  - 상단 취소 / 저장
  - 프로필 사진 변경 영역
  - 닉네임 입력
  - 나이 / 키 / 몸무게 입력
  - 리스트형 폼 기반 편집 구조
  - 입력 제한 / 유효성 안내 / 저장 중 로딩 상태

## 4. 데이터 흐름

### 사용 데이터
- Firestore 컬렉션:
  - `users/{uid}`: 닉네임, 프로필 이미지, 나이, 키, 몸무게
  - `users/{uid}/runHistory`: 누적 거리, 운동 시간, 평균 페이스 산출
  - `users/{uid}/recentSongs`: 최근 들은 노래
- UserDefaults:
  - `nickname`
  - `age`
  - `height`
  - `weight`
  - `profileImageBase64`

### 상태 관리
- View:
  - `MyView`
  - `MyProfileDetailView` 신규
  - `ProfileEditView` 개선
- ViewModel:
  - `MyViewModel`
  - `MyProfileDetailViewModel` 신규
- 주요 상태
  - 내 프로필 기본 정보
  - 러닝 통계 요약
  - 최근 들은 노래 목록
  - 편집 입력값
  - 저장 중 상태
  - 저장 실패 에러 메시지

## 8. 특이 사항 / 기술 검토

- 친구 프로필 화면과 내 프로필 상세 화면은 시각 구조가 유사하지만 액션은 다르다. 친구 프로필은 관계 버튼이 중심이고, 내 프로필은 `프로필 편집`이 중심이다.
- 공통화는 과하게 하지 않고, 레이아웃과 데이터 포맷 수준만 유사하게 유지하는 것이 안전하다.
- 인스타그램 느낌은 그대로 복제하기보다, iOS HIG를 벗어나지 않는 범위에서 `큰 프로필 이미지`, `명확한 편집 CTA`, `간결한 리스트형 입력`, `즉시 이해 가능한 저장 흐름`으로 해석한다.
- 최근 들은 노래는 기존 `recentSongs` 저장 구조를 재사용한다.
