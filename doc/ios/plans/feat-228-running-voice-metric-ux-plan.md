# 러닝 음성 안내·상단 지표 선택 보완 계획

## 목표
- 시작·종료 안내를 한 문장 오디오로 합성해 중간 끊김을 제거한다.
- MeloTTS 출력의 속도와 고주파 강조를 조정해 더 밝고 또렷하게 들리게 한다.
- iPhone 러닝 화면 상단 시간 영역을 하단 지표와 같은 탭 순환 방식으로 제공한다.
- #227의 Watch 백그라운드 시간·거리·페이스 기준을 유지한다.

## 검토 기준
- 시작 안내가 “운동을 시작합니다.” 한 문장으로 자연스럽게 재생된다.
- 종료 안내가 “운동을 완료했습니다.”부터 거리·시간·평균 페이스까지 한 번에 이어진다.
- 상단 지표를 탭하면 시간·거리·현재 페이스·평균 페이스 등이 순환된다.
- 실기기 빌드·음성·Watch 백그라운드 검증은 사용자가 수행한다.
