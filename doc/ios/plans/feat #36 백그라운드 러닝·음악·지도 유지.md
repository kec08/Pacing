## 1. 목적 및 배경

현재 앱은 포그라운드에서는 러닝 거리, 경로, 음악, 주변 러너 브로드캐스트가 동작하지만, 백그라운드 전환 시 러닝 앱으로서 기대되는 지속성이 충분히 보장되지 않는다.
러닝 앱에서는 화면을 끄거나 다른 앱으로 이동해도 위치 추적과 음악 재생이 끊기지 않아야 하고, 친구 지도에서도 내 위치가 계속 보이는 것이 핵심 사용성이다.

이번 작업은 백그라운드에서도 러닝이 계속 기록되고, 음악 재생이 유지되며, 지도 기반 위치 브로드캐스트도 가능한 범위에서 계속 유지되도록 앱 설정과 실행 흐름을 정리한다.

## 2. 사용자 시나리오

```
사용자가 러닝을 시작한다
→ 화면을 끄거나 다른 앱으로 이동해도 러닝 시간/거리/경로 기록이 계속된다
→ 재생 중인 음악도 중단되지 않는다
→ 백그라운드 상태에서도 위치 업데이트가 이어져 친구 지도에서 내 러너 핀이 계속 보인다
→ 다시 앱으로 돌아오면 누락 없이 현재 러닝 상태와 지도가 이어진다
```

## 3. 화면 구성

### 주요 화면
- 러닝 화면
- 친구 지도 / 주변 러너 표시 영역

### UI 요소
- 별도 신규 화면 추가 없음
- 필요 시 백그라운드 위치 사용 안내 문구는 기존 권한 문구 기준 유지

## 4. 데이터 흐름

## 8. 특이 사항 / 기술 검토

- iOS에서 백그라운드 러닝 기록은 `Always` 권한, `location` background mode, `allowsBackgroundLocationUpdates` 설정이 핵심이다.
- `Timer` 기반 주기 업로드는 백그라운드에서 신뢰성이 떨어질 수 있으므로, 위치 업데이트 수신 시점에 브로드캐스트를 함께 갱신하는 보완이 필요하다.
- `systemMusicPlayer`는 Apple Music 재생 연속성에는 유리하지만, 앱 오디오 세션 카테고리가 적절하지 않으면 백그라운드 유지가 불안정할 수 있다.
- 실제 백그라운드 동작은 시뮬레이터보다 실기기 확인이 중요하다.
- 최종 커밋, 푸시, PR은 QA 후 진행한다.
