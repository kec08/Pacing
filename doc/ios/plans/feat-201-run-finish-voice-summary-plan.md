# feat: 러닝 종료 음성 요약 안내 계획서

> **상태**: 검토 대기
> **작성일**: 2026-09-30  
> **기준 브랜치**: `dev`

## 목적

러닝이 완료되면 “운동을 완료했습니다”와 함께 거리, 총 시간, 평균 페이스를 한국어 음성으로 한 번 안내한다. 음성 안내 동안 재생 중인 음악은 잠시 멈추고, 안내가 끝나면 자동으로 이어서 재생한다.

관련 이슈: [#201](https://github.com/kec08/Pacing/issues/201)

## 구현 범위

- 종료가 실제로 완료된 시점에만 종료 음성 안내를 호출한다.
- 거리(km), 총 경과 시간, 평균 페이스를 사용자에게 자연스러운 한국어 문장으로 포맷한다.
- iPhone과 Watch 어느 쪽에서 종료하더라도 iPhone 음성 안내는 한 번만 실행되게 한다.
- 기존 `LapVoiceAnnouncementService`의 음악 일시정지·안내 종료 후 자동 재개 정책을 재사용한다.
- 종료 실패·취소·빈 수치에서는 잘못된 완료 안내를 하지 않는다.

## 완료 기준

- 종료 음성에 운동 완료, 거리, 시간, 평균 페이스가 포함된다.
- 완료 수치가 러닝 요약 화면의 수치와 일치한다.
- Watch·iPhone 양방향 종료에도 중복 음성 안내가 없다.
- 음성 안내 뒤 재생 전이던 음악만 자동 재개된다.

## 검증 계획

1. 종료 음성 문구의 수치·단위·경계값 관련 단위 테스트를 추가 또는 보완한다.
2. Generic iOS·watchOS Debug 빌드와 `git diff --check`를 실행한다.
3. 실기기에서 iPhone/Watch 각각으로 종료하고, 음악 재생 중 안내·자동 재개를 확인한다.

## 브랜치 및 커밋 계획

- 검토 승인 후 최신 `dev`에서 `feat/201-run-finish-voice-summary` 브랜치를 생성한다.
- 음성 모델·종료 호출·테스트를 논리적 단위로 나누어 커밋한다.
- #201만 포함한 PR을 생성하며 최종 병합은 개발자가 직접 진행한다.
