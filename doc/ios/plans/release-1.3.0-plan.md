# Pacing 1.3.0 릴리스 계획

- 이슈: [#230](https://github.com/kec08/Pacing/issues/230)
- 기준: `main`의 1.2.2와 `dev`의 병합 PR·코드 비교

1. `dev`에 병합된 기능만 릴리스 설명에 포함하고 README에 주요 변경을 정리한다.
2. iPhone 앱과 Watch 앱의 마케팅 버전을 1.3.0으로 설정한다.
3. App Store 업데이트 문구와 심사 메모를 작성한다. 심사 계정 비밀번호는 저장소에 기록하지 않는다.
4. 빌드와 버전 설정을 확인하고 main 대상 PR을 만든다. 실기기 QA와 최종 병합은 개발자가 진행한다.

아카이브 업로드에서 발견된 Watch 아이콘 알파 채널 오류를 릴리스 전에 수정한다. 바이너리 패키지의 dSYM 경고는 아카이브와 배포 패키지를 확인해 처리 가능 범위를 보고한다.

main과 dev의 Git 이력이 갈라져 있으므로 PR의 병합 가능 여부를 확인한다.
