# 러닝 기록 카메라 공유 계획서

## 목적

러닝 활동 상세 화면에서 사용자가 자신의 기록을 선택한 투명 오버레이 양식과 함께 카메라 사진으로 촬영하고, iOS 공유 시트로 전달할 수 있게 한다.

카메라 화면은 세로 전체 화면을 유지해 사진의 위·아래가 잘리지 않으며, 페이싱 로고는 좌측 상단, 선택한 기록 양식은 하단에 흰색·투명 배경으로 표시한다.

## 사용자 흐름

1. 사용자가 내 러닝 활동 상세 화면 우측 상단의 글래스 스타일 공유 버튼을 누른다.
2. 공유 양식 선택 화면에서 가로 1줄의 3개 미리보기 카드를 확인하고 하나를 선택한다.
3. 카메라 권한을 확인한 뒤, 후면 카메라 전체 화면 미리보기를 연다.
4. 좌측 상단의 페이싱 로고와 화면 하단의 선택 양식을 확인하며 사진을 촬영한다.
5. 촬영 결과를 확인한 뒤 시스템 공유 시트에서 원하는 앱으로 공유하거나 재촬영·닫기를 선택한다.

## 공유 양식

| 양식 | 표시 정보 | 화면 배치 |
| --- | --- | --- |
| 거리 | 거리(km) | 하단 중앙의 큰 거리 값 |
| 핵심 기록 | 총 시간 · 거리(km) · 평균 페이스 | 하단 가로 3열 |
| 경로 기록 | 세로 거리(km) · 경로 · 위치 | 하단 세로 정보 영역 |

- 모든 양식은 투명 배경과 흰색 텍스트·선으로 구성한다.
- 제공된 `페이싱_로고-Photoroom 2.svg`를 iOS 에셋으로 등록하고, 카메라 좌측 상단에 표시한다.
- 접근성은 양식 선택 상태, 카메라 권한 오류, 촬영·재촬영·공유 동작을 각각 음성 안내한다.

### 양식 디자인 명세

세 양식은 Nike Run Club의 카메라 공유 경험처럼 사진을 가리지 않는 하단 오버레이로 직접 제작한다. 검은 카드나 별도 배경 이미지는 사용하지 않고, 모든 텍스트·선은 흰색으로 렌더링한다.

1. **거리 양식**
   - 사진 하단 좌측에 `5.10`처럼 큰 거리 수치를 표시하고 바로 아래에 `KM`을 둔다.
   - 수치는 둥근 고대비 굵은 글꼴, 단위는 작고 자간을 넓힌 대문자 스타일로 표현한다.

2. **핵심 기록 양식**
   - 사진 하단 안전 영역에 3열 가로 레이아웃을 둔다.
   - `총 시간` · `KM` · `평균 페이스` 순서로 각 열의 큰 값과 작은 캡션을 표시한다.
   - 열 사이에는 낮은 투명도의 세로 구분선을 사용해 사진 위에서도 읽기 쉽게 한다.

3. **경로 기록 양식**
   - 사진 하단 좌측에서 시작하는 세로 레이아웃으로 `거리`, `경로 미니 라인`, `위치`를 위에서 아래로 배치한다.
   - 경로는 저장된 좌표를 단색 흰색 선으로 정규화해 표시하며, 시작·도착은 작은 점으로 구분한다.
   - 위치는 저장된 경로의 시작 지점 지명 우선, 실패 시 좌표 또는 `위치 정보 없음`을 표시한다.

- 양식 선택 화면에는 실제 카메라 프리뷰를 열기 전에 위 세 디자인을 3개의 축소 미리보기 카드로 가로 한 줄에 제공한다.
- 선택된 카드는 흰색 테두리와 체크 표시로 구분하며, 선택 전에도 각 양식의 정보 구조가 식별돼야 한다.

## 구현 계획

### 1. 활동 상세 진입점

- `RunActivityDetailView` 우측 상단에 글래스 스타일의 공유 버튼을 추가한다.
- 친구 활동 상세에서는 개인 기록·위치 정보를 외부 공유하지 않도록, 내 기록 화면에서만 버튼을 노출한다.

### 2. 양식 선택 UI

- `RunShareTemplate` 도메인 모델로 3개 양식과 표시 데이터를 정의한다.
- SwiftUI 가로 스크롤이 아닌 한 줄 3열 고정 레이아웃으로 미리보기와 선택 상태를 제공한다.
- 선택한 양식은 카메라 화면까지 명시적으로 전달한다.

### 3. 카메라 및 사진 합성

- `AVCaptureSession` 기반 후면 카메라 프리뷰를 전체 화면으로 표시한다.
- 사진 출력은 미리보기 비율과 독립적으로 최대 사진 해상도를 유지하고, 결과 이미지 자체에는 상·하단 크롭을 적용하지 않는다.
- 사진 촬영 후 원본 이미지 위에 페이싱 로고와 선택된 SwiftUI 양식을 렌더링해 합성한다.
- 합성 레이아웃은 프리뷰와 동일한 세로 전체 화면 좌표계를 사용하되, 카메라 원본 이미지 비율을 보존한다.

### 4. 권한·공유·오류 상태

- `NSCameraUsageDescription`을 추가하고 권한 미결정·거절·카메라 미지원 상태를 처리한다.
- 촬영 뒤 재촬영과 iOS `UIActivityViewController` 공유를 제공한다.
- 카메라 초기화·촬영 실패는 원인을 안내하고 안전하게 선택 화면으로 돌아갈 수 있게 한다.

### 5. 테스트 및 QA

- 템플릿별 표시 데이터와 선택 상태 단위 테스트를 추가한다.
- 카메라 권한 상태 분기와 이미지 합성 레이아웃 계산을 테스트 가능한 정책으로 분리한다.
- Simulator 빌드·단위 테스트를 실행한다.
- 실기기에서 세 양식, 권한 허용·거절, 세로 전체 화면·상하 무크롭, 재촬영, 카카오톡/사진/공유 시트 동작을 확인한다.

## 기술적 고려 사항

- `AVCapturePhotoOutput`의 고해상도 결과를 기준으로 합성해, 화면 프리뷰 비율 때문에 사진이 잘리지 않게 한다.
- 카메라 프리뷰의 화면 채움은 촬영 결과의 원본 보존과 별개로 취급한다. 프리뷰에서 가장자리 일부가 보이지 않을 수 있어도 저장·공유 이미지는 원본 전체를 유지한다.
- UI 표현은 View에 두고, 권한·세션·촬영은 Repository/Service, 양식 선택·상태 전이는 ViewModel으로 분리한다.
- 위치는 새 GPS 좌표를 수집하지 않고 저장된 러닝 경로의 시작 좌표를 사람이 읽을 수 있는 지명으로 변환한다. 변환 실패 시 좌표 텍스트 또는 위치 정보 없음으로 안전하게 표시한다.

## 제외 범위

- 사진 라이브러리에서 기존 사진을 선택하는 기능
- 촬영 이미지의 서버 저장, 피드 게시, SNS 계정 직접 연동
- 동영상·라이브 포토 촬영
- Watch 앱 공유 기능
