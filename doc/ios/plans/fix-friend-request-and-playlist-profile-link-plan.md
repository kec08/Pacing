# 친구 요청 복구 및 친구 플레이리스트 프로필 링크 계획서

> **관련 이슈**: [#205](https://github.com/kec08/Pacing/issues/205)

---

## 목적

친구 추가 요청이 실패하는 원인을 Firestore 규칙·데이터 상태·클라이언트 요청 흐름에서 확인하고 기존 친구 추가 경험을 복구한다. 음악 탭의 친구 플레이리스트 상세 화면에서는 소유자 이름을 Pacing 메인 컬러 링크로 제공해 해당 친구의 프로필로 자연스럽게 이동하게 한다.

## 구현 범위

- 친구 요청 생성 실패의 실제 원인 확인 및 최소 수정
- 친구 요청 재전송·취소·수락 기존 상태 전환 회귀 검증
- 공유 플레이리스트 소유자 UID를 사용한 친구 프로필 이동
- 친구 소유 플레이리스트에만 링크를 표시하고 Apple Music 추천 콘텐츠에는 적용하지 않음
- 링크의 접근성 레이블·터치 영역·네비게이션 동작 보장

## 데이터 흐름

```
친구 추가 버튼
→ Firestore friendRequests/{fromUID}_{toUID}
→ Firestore 보안 규칙 검증
→ 요청 수신자 목록 및 알림

친구 플레이리스트 상세
→ sharedPlaylist.ownerUID
→ FriendProfileView(friend: FriendUser)
```
