# MeloTTS 온디바이스 오프라인 음성 안내 계획

> 브랜치: `feat/222-melotts-offline` · 관련 이슈: [#222](https://github.com/kec08/Pacing/issues/222) · 기준: 머지된 `dev`

## 목표
- iPhone 러닝 상태, 1km 랩, 종료 안내를 MeloTTS 한국어 음성으로 재생한다.
- 음악 ducking과 안내 순서, 러닝 거리 측정을 유지한다.
- 네트워크 없이 동작하고 안내 누락을 피한다.

## 조사·설계
1. 공식 MeloTTS와 한국어 ONNX 변환본의 모델 출처, 라이선스, 입출력·전처리 요구사항을 고정한다.
2. iOS ONNX Runtime을 Swift Package로 연결하고 INT8 모델을 앱 번들에 넣는다.
3. 러닝 안내 문장에 필요한 숫자·단위·고정 표현을 한국어로 정규화하고 원본 G2P와 비교해 토큰을 만든다. 모델 입력이 유효하지 않으면 기존 AVSpeechSynthesizer로 즉시 대체한다.
4. 모델은 러닝 시작 전에 비동기로 미리 로드한다. 추론·PCM 변환은 화면/위치 처리 밖에서 수행하고, 음성 안내는 순서대로 큐에 넣는다. 안내가 겹칠 때도 기록 계산을 기다리게 하지 않는다.
5. 모델 음성을 기존 오디오 세션의 ducking으로 재생하고 완료·취소 후 세션을 복구한다.

## 검증
- iPhone/Watch Debug 빌드, 한국어 안내 텍스트·토큰·WAV 출력의 작은 자동 테스트.
- 지원 iOS Simulator에서 실제 모델로 짧은 안내와 연속 1km 안내를 생성해 오디오 파일을 확인한다.
- iPhone 실기기에서 첫 발화/연속 발화 지연·메모리·발음·음악 ducking·백그라운드/이어폰 경로를 측정한다.

## 제약
- 커뮤니티 ONNX 변환본이 공식 iOS SDK는 아니다. 모델/사전 배포 라이선스와 결과 품질을 확인한다.
- 실기기 성능과 오디오 출력은 이 환경에서 보장할 수 없다. 재생 실패 시 시스템 한국어 TTS로 대체한다.
- PR은 별도 요청 또는 실기기 QA 준비 후 진행한다.

## 구현 검토 (2026-10-23)

- [x] 공식 ONNX Runtime Swift Package 1.24.2를 iPhone 타깃에 연결하고 한국어 INT8 모델(53.5 MB)을 번들에 포함했다.
- [x] g2pkk 0.1.2로 러닝 안내의 고정 문장과 숫자·단위 발음을 빌드 시 생성한다. iPhone은 Python·네트워크 없이 토큰을 사용한다.
- [x] 모델 준비와 추론을 별도 큐로 옮기고, 1.2초 초과·미준비·지원 범위 밖 문장은 기존 한국어 음성으로 대체한다.
- [x] WAV 재생은 기존 음성 안내의 음악 ducking과 큐 순서를 사용한다.
- [ ] iPhone 실기기에서 MeloTTS 발음·첫 발화·연속 발화 지연, 메모리, 이어폰/음악 경로를 확인한다.
## 실기기 발음 오류 수정 (2026-10-23)

- 실제 ONNX 체크포인트의 `melotts_kr_config.json` 심볼 순서를 발음 사전의 기준으로 사용한다.
- 숫자는 한글 한자어 표기(영, 일, 이, …, 십, 이십)를 만든 뒤 g2pkk로 변환한다.
- 시작·일시정지·재개 클립을 같은 심볼 순서로 다시 생성한다.
- iPhone 대상 빌드와 생성된 안내 샘플을 확인하고 실기기 청취 QA 결과를 기다린다.
