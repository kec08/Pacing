# 같이 듣기·러닝 지도 경험 개선 계획서

## 1. 목적

같이 듣기 참여자의 실제 프로필 이미지를 일관되게 표시하고, 정지 상태 GPS 오차로 발생하는 비정상 페이스를 막는다. 또한 러닝 중에도 사용자가 내 위치로 돌아가 자동 추적을 다시 시작할 수 있도록 지도 제어를 복구한다.

## 2. 원인

| 항목 | 확인된 원인 |
| --- | --- |
| 같이 듣기 프로필 | `ListenSession`과 RTDB 세션 데이터에 호스트/게스트 프로필 이미지 필드가 없어 이니셜 아바타만 렌더링됨 |
| 친구 음악 카드 | 지도 핀이 내 러너와 친구 러너에 서로 다른 카드 표면·색상을 적용해 UI가 일관되지 않음 |
| 정지 중 페이스 | 거리 이동량 검증 없이 `경과 시간 ÷ 누적 거리`로 페이스를 계산해 GPS 미세 오차에도 비정상 값이 표시됨 |
| 내 위치 버튼 | 러닝 중 버튼은 존재하지만 통계 오버레이보다 아래 레이어에 있어 화면에서 가려질 수 있음 |

## 3. 구현 계획

### 3.1 같이 듣기 참여자 프로필

- `ListenSession` 및 RTDB 세션에 `hostProfileImageBase64`, `guestProfileImageBase64`를 추가한다.
- 요청 생성 시 내 프로필과 선택한 친구 러너의 프로필을 세션 스냅샷으로 저장하고, 수신 요청·활성 세션 파싱에 반영한다.
- 같이 듣기 요청 배너와 시트 참가자 행에서 동일한 프로필 아바타 컴포넌트를 사용한다.
- 이미지가 없거나 디코딩에 실패하면 현재의 이니셜 아바타로 안전하게 대체한다.

### 3.2 친구 음악 카드 UI 통일

- 지도 핀의 내 러너/친구 러너 카드에 공통 레이아웃과 색상 규칙을 적용한다.
- 친구 프로필·곡 정보·접힘 상태는 유지하고, 내 카드에만 적용된 색상 분기를 제거해 같은 음악 카드 경험을 제공한다.

### 3.3 이동 검증 후 페이스 계산

- 러닝 시작 및 재개 시 페이스 계산 상태를 초기화한다.
- GPS 정확도와 최소 누적 이동 거리 기준을 통과하기 전에는 `currentPace`를 0으로 유지해 `--'--\"`를 표시한다.
- 임계값을 넘은 유효 이동부터 평균/랩 페이스를 계산하며, 정지·미세 GPS 흔들림은 거리와 페이스에 반영하지 않는다.
- 페이스 정책을 순수한 계산 단위로 분리하거나 ViewModel 단위 테스트를 추가해 정지·유효 이동·랩 완주 케이스를 검증한다.

### 3.4 러닝 중 지도 자동 추적 제어

- 러닝/일시정지 상태에서 +/- 버튼은 숨기고 내 위치 버튼만 노출한다.
- 버튼을 통계 패널보다 높은 레이어의 우측 고정 오버레이로 이동해 항상 터치 가능하게 한다.
- 지도 드래그·확대/축소 시 자동 추적을 해제하고, 내 위치 버튼 탭 시 1km 범위로 재중심·자동 추적을 즉시 재개한다.
- 접근성 레이블과 추적 상태별 시각 피드백을 추가한다.

## 4. QA 기준

- 프로필 이미지가 있는 호스트와 게스트 모두 요청 배너·같이 듣기 시트에 실제 이미지가 표시된다.
- 프로필 이미지가 없는 계정은 이니셜 폴백이 표시된다.
- 내 핀과 친구 핀의 음악 카드 레이아웃·색상이 동일하다.
- 정지 상태 30초 이상에서 페이스가 `--'--\"`로 유지되고, 유효 이동 뒤에만 정상 페이스가 나온다.
- 러닝 중 지도 수동 조작 뒤 내 위치 버튼이 보이며, 탭하면 내 위치 추적이 재개된다.
- 기존 같이 듣기 요청/수락/종료와 러닝 저장 흐름에 회귀가 없다.
