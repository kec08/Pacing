# 친구 플레이리스트·앨범 개별 곡 연속 재생 수정 계획서

> **상태**: 개발 완료 · 실기기 QA 대기
> **작성일**: 2026-08-05
> **관련 이슈**: #91
> **브랜치**: `fix/91-friend-playlist-queue`

---

## 1. 목적 및 배경

친구가 공유한 플레이리스트 또는 앨범 상세 화면에서 수록곡 하나를 선택해 재생하면, 선택한 한 곡만 재생되고 종료 후 다음 곡으로 넘어가지 않는 문제가 있다.

개별 곡을 선택한 경우에도 현재 상세 화면의 전체 수록곡을 재생 큐로 구성해, 선택 곡부터 마지막 곡까지 순서대로 재생되도록 수정한다.

## 2. 사용자 시나리오

```
사용자가 친구 플레이리스트 또는 앨범 상세 화면에 진입하면
→ 수록곡 중 원하는 곡을 선택하고
→ 선택한 곡부터 현재 목록의 다음 곡들이 순서대로 재생된다.
```

## 3. 범위 및 UX 정책

| 구분 | 동작 |
|---|---|
| 친구 플레이리스트 상세 | 개별 곡 선택 시 전체 수록곡을 큐로 구성하고, 선택한 곡부터 재생한다. |
| 친구 앨범 상세 | 개별 곡 선택 시 전체 수록곡을 큐로 구성하고, 선택한 곡부터 재생한다. |
| 다음 곡 전환 | 현재 곡 종료 또는 미니플레이어의 다음 곡 동작 시 큐의 다음 곡으로 전환한다. |
| 마지막 곡 | 마지막 곡 종료 후에는 기존 플레이어 종료 상태 정책을 유지한다. |
| 예외 상태 | 빈 목록, 재생 불가 곡, 재생 URL 누락은 기존 오류/비활성 처리 정책을 유지한다. |

## 4. 기술 검토 및 데이터 흐름

1. 친구 플레이리스트·앨범 상세의 곡 선택 이벤트가 단일 곡 재생 경로를 호출하는지 확인한다.
2. 상세 화면에서 로드한 정렬된 수록곡 목록을 재생 계층에 전달할 수 있는지 확인한다.
3. 공통 플레이어가 재생 큐와 현재 인덱스를 보유하도록 기존 구조를 점검한다.
4. 선택된 곡의 인덱스를 시작점으로 설정하고, 재생 완료 이벤트에서 다음 인덱스를 재생하도록 연결한다.
5. 전체 재생, 미니플레이어 다음 곡, 다른 음악 화면의 재생 흐름에는 회귀가 없도록 공통 로직 변경 범위를 최소화한다.

- [x] Task 2: 개별 곡 선택 시 현재 상세 화면의 전체 수록곡과 선택 인덱스를 전달하도록 수정한다.
- [x] Task 3: 재생 완료 시 다음 큐 항목으로 전환되는 로직과 마지막 곡 종료 처리를 검증·보완한다.

## 6. 완료 기준

- [ ] 친구 플레이리스트 상세에서 임의의 중간 곡을 선택하면 다음 수록곡이 자동 재생된다.
- [ ] 친구 앨범 상세에서 임의의 중간 곡을 선택하면 다음 수록곡이 자동 재생된다.
- [ ] 첫 곡·중간 곡·마지막 곡 선택 시 현재 재생 곡과 다음 곡 전환 순서가 목록과 일치한다.
- [ ] 기존 전체 재생과 미니플레이어의 다음 곡 기능이 정상 동작한다.
- [ ] 마지막 곡 이후의 동작과 재생 실패 상태가 기존 UX와 충돌하지 않는다.
- [ ] Debug 빌드 및 실기기 또는 가능한 범위의 재생 QA를 통과한다.

## 8. 특이 사항

- 구현 전 현재 재생 엔진이 MusicKit 큐를 직접 관리하는지, 앱 내부 큐를 별도로 관리하는지 확인이 필요하다.
- 친구 상세 화면의 데이터가 비동기로 보강되는 경우, 실제 화면에 표시되는 정렬 순서와 재생 큐 순서가 동일해야 한다.
- 이번 수정은 친구 플레이리스트·앨범의 개별 곡 선택 재생에 한정하며, 셔플·반복 정책 변경은 범위에 포함하지 않는다.
