# 소셜 로그인 공통 로딩 화면 개선 계획서

## 배경

Apple 로그인은 인증 처리 중 브랜드 로딩 화면을 표시하지만, Google·Kakao·Naver 및 이메일 로그인·회원가입은 기존 화면의 인디케이터를 표시한다. 로그인 방식별 대기 경험을 통일하고, 로딩 상태를 더 쉽게 인지할 수 있도록 개선한다.

## 목표

- 모든 로그인 및 이메일 회원가입의 인증 처리 중 브랜드 로딩 화면을 표시한다.
- 로딩 인디케이터의 크기를 소폭 키워 가시성을 높인다.
- 외부 로그인 취소 및 오류 시 기존 로그인 화면과 오류 안내로 안전하게 복귀한다.

## 구현 범위

1. `LoginView`, `EmailLoginView`, `SignUpView`의 `authVM.isLoading` 상태를 전체 화면 로딩 오버레이로 연결한다.
2. 기존 로그인·회원가입 버튼 영역 `ProgressView`를 제거해 로그인 수단별 UI 차이를 없앤다.
3. 앱 아이콘, 서비스명, 슬로건을 포함한 재사용 가능한 공통 브랜드 로딩 구성을 적용한다.
4. 로그인 중 인디케이터를 기존보다 크게 표시한다.
5. 앱 활성화 시 임의로 로딩을 해제하던 타이머를 제거하고, 각 인증 SDK의 성공·실패·취소 완료 시점에만 로딩을 종료한다.

## 검증

- Apple, Google, Kakao, Naver, 이메일 로그인 및 회원가입 시작 시 동일한 로딩 화면이 노출되는지 확인한다.
- 외부 로그인 앱에서 복귀한 뒤 인증이 완료될 때까지 로딩 화면이 유지되는지 확인한다.
- 외부 로그인 취소·실패 시 로그인 버튼과 오류 안내가 복원되는지 확인한다.
- 다크 모드 및 작은 화면에서 로고·인디케이터가 잘리지 않는지 확인한다.
- Debug iOS Simulator 빌드와 `git diff --check`를 통과한다.

## 비범위

- 각 로그인 SDK의 인증·토큰 처리 로직 변경
- 로그인 화면의 버튼 디자인 변경
