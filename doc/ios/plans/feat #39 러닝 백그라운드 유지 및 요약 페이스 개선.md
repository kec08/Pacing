# feat #39 러닝 백그라운드 유지 및 요약 페이스 개선

> **브랜치**: `feat/39-running-background-summary-pace`

## 1. 목적 및 배경

현재 러닝 화면은 앱이 백그라운드로 전환되거나 화면이 꺼질 때 측정이 안정적으로 이어지지 않아 실제 러닝 앱 사용 흐름이 끊긴다.
특히 백그라운드 상태에서 전달되는 위치 배치 중 중간 좌표가 경로에 충분히 반영되지 않으면, 복귀 후 이동 경로 마커가 끊겨 보일 수 있다.
또한 러닝 종료 요약 화면에서 칼로리 값이 2줄로 보이고, `1km당 페이스` 문구와 실제 km별 페이스 상세 정보가 사용자 기대와 다르게 제공되고 있다.

이번 작업은 러닝 측정의 백그라운드 지속성을 보강하고, 종료 요약 화면을 `평균 페이스` 중심으로 재구성해 실제 러닝 결과를 더 명확하게 전달하는 것을 목표로 한다.

## 2. 사용자 시나리오

```
사용자가 러닝을 시작하면
→ 화면을 끄거나 다른 앱으로 이동해도 거리와 시간 측정이 계속 이어지고
→ 러닝 종료 후 요약 화면에서 총 평균 페이스를 확인하고
→ 1km, 2km, 3km 등 각 구간별 평균 페이스를 아래 목록에서 자연스럽게 확인한다
→ 앱 복귀 후에도 백그라운드 동안 이동한 경로 마커가 이어서 표시된다
```

## 3. 화면 구성

### 주요 화면
- 러닝 화면: 백그라운드 전환 중에도 측정이 유지되어야 함
- 러닝 종료 요약 화면: 상단 핵심 지표와 km별 평균 페이스 목록 표시

### UI 요소
- 상단 요약 카드: 시간, 평균 페이스, 칼로리
- 평균 페이스 섹션: 기존 `1km당 페이스` 문구를 `평균 페이스`로 변경
- km별 페이스 리스트: `1km`, `2km`, `3km` 형식의 평균 페이스 행 표시

## 4. 데이터 흐름

### 사용 데이터
- `CLLocationManager` 위치 업데이트
- `RunSummaryView` 종료 요약 표시 데이터
- Firestore `runHistory` 저장 데이터

### 상태 관리
- `LocationManager`: 백그라운드 위치 추적 설정 유지
- `RunningViewModel`: 총 평균 페이스, km별 랩 평균 페이스 계산
- `RunSummaryView`: 요약 카드 및 km별 평균 페이스 렌더링

## 5. 작업 목록 (Tasks)

- [ ] Task 1: 백그라운드 측정 유지에 필요한 앱 설정과 위치 매니저 흐름 점검 및 보강
- [ ] Task 2: 백그라운드 위치 배치 전체를 경로와 거리 계산에 반영해 이동 경로 마커가 이어지도록 보강
- [ ] Task 3: 러닝 중 km 랩 기준 평균 페이스 데이터를 계산하고 종료 시점까지 유지
- [ ] Task 4: 종료 요약 화면에서 칼로리 레이아웃을 1줄로 정리
- [ ] Task 5: `1km당 페이스` 문구를 `평균 페이스`로 변경하고 km별 평균 페이스 목록 추가
- [ ] Task 6: 빌드 및 QA 결과 정리

## 6. 완료 기준 (Acceptance Criteria)

- [ ] 화면 잠금 또는 앱 백그라운드 전환 후에도 러닝 측정이 이어지도록 필요한 설정이 반영된다
- [ ] 앱 복귀 후에도 백그라운드 동안 기록된 이동 경로가 지도에 이어서 표시된다
- [ ] 종료 요약 카드의 칼로리 값이 줄바꿈 없이 1줄로 표시된다
- [ ] 종료 요약 화면의 문구가 `평균 페이스`로 표기된다
- [ ] 종료 요약 화면에서 `1km`, `2km`, `3km` 등 km별 평균 페이스가 거리 구간에 맞게 표시된다
- [ ] Debug 빌드 또는 최소 컴파일 검증이 가능하다

## 8. 특이 사항 / 기술 검토

- `allowsBackgroundLocationUpdates`만으로는 충분하지 않고 `Info.plist`의 `UIBackgroundModes` 설정 정합성이 필요하다.
- km별 평균 페이스는 실시간 표시용 현재 페이스와 별도로 누적 거리/시간 기준 랩 결과를 저장해야 종료 화면에서 안정적으로 재사용할 수 있다.
- 마지막 1km 미만 구간은 km별 리스트에 포함할지 여부를 명확히 해야 하며, 이번 작업에서는 사용자 요청 기준으로 완료된 1km 단위만 우선 표시한다.
- 백그라운드 동작은 시뮬레이터보다 실기기 검증이 중요하다.
