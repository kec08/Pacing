# 러닝 종료 요약 전체 평균 페이스 정합성 수정 계획서

## 1. 목적 및 배경

러닝 종료 요약 화면의 `평균 페이스`가 전체 러닝 시간과 전체 거리 기준이 아니라, 종료 직전 또는 재개 뒤의 구간 페이스처럼 표시될 수 있다. 사용자에게 표시되는 총 시간·총 거리와 동일한 기준으로 전체 평균 페이스를 계산·표시·저장하도록 정합성을 맞춘다.

## 2. 조사 결과

- 종료 요약 화면 `RunSummaryView`는 `RunningViewModel.avgPace`를 `평균 페이스`로 표시한다.
- `avgPace`는 GPS 유효 구간 시간인 `activeElapsedSeconds / distance`로 계산된다. 반면 종료 화면의 총 시간은 일시정지를 제외한 `elapsedSeconds`이므로, 두 지표의 시간 기준이 다르다.
- `resume()`에서 `activeElapsedSeconds`를 `0`으로 재설정한다. 따라서 일시정지 후 재개한 러닝은 km 랩 계산용 누적 시간도 끊길 수 있다.
- km 랩 페이스는 `completedLapPaces`로 별도 관리되므로, 전체 평균 페이스와 혼용되지 않아야 한다.

## 3. 구현 방향

### Task 1. 평균 페이스 시간 기준 분리 및 누적

- 종료 요약의 전체 평균 페이스는 일시정지 시간을 제외한 `elapsedSeconds ÷ distance`로 계산한다.
- GPS 유효 구간 시간은 km 랩 계산 용도로 유지하되, 재개 시 초기화하지 않도록 수정한다.
- 일시정지 시간은 종료 요약의 전체 평균 페이스에서 계속 제외한다.

### Task 2. 종료·저장 데이터 정합성 보장

- 종료 요약 화면, 저장 `RunRecord`, 완료 km 랩 계산이 각각의 의도한 시간 기준을 사용하도록 확인한다.
- 전체 평균 페이스는 전체 누적 이동 시간 ÷ 전체 거리로 계산하고, km 랩 페이스는 각 km 구간 시간 ÷ 해당 구간 거리로 유지한다.

### Task 3. 회귀 테스트 및 QA

- 시작 → 주행 → 일시정지 → 재개 → 종료 시, 총 거리와 누적 이동 시간 기준의 평균 페이스를 단위 테스트로 검증한다.
- 일시정지 시간이 평균 페이스에 포함되지 않는지 검증한다.
- 종료 요약, 저장 기록, km별 랩 페이스가 서로 혼동되지 않는지 시뮬레이터 QA를 수행한다.

## 4. 완료 기준

- [ ] 일시정지 없이 종료한 러닝의 평균 페이스가 총 이동 시간 ÷ 총 거리와 일치한다.
- [ ] 일시정지 후 재개한 러닝도 재개 전·후 이동 시간을 모두 반영한 평균 페이스가 표시된다.
- [ ] 종료 요약의 총 시간·평균 페이스·저장 기록이 동일한 계산 기준을 사용한다.
- [ ] km별 랩 페이스 표시는 기존 동작을 유지한다.
- [ ] 관련 단위 테스트 및 Debug iOS Simulator 빌드가 통과한다.
