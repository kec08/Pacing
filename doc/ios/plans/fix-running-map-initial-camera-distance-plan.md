## 문제 및 원인

러닝 탭 최초 진입 시 `.automatic` 지도 카메라의 변경 콜백이 `mapZoomDistance`를 작은 값으로 바꿀 수 있다. 첫 위치 수신도 그 변경 가능한 값을 사용해 카메라를 보정하므로 지도가 과도하게 확대된다. 내 위치 버튼은 고정된 1,000m 거리를 직접 전달하므로 적절한 범위로 보인다.

## 설계

| 구간 | 동작 |
|---|---|
| 최초 위치 수신/이미 확보된 위치로 진입 | 내 위치 버튼과 같은 불변 1,000m 거리로 카메라 보정 |
| 이후 수동 줌·이동 | 기존 `onMapCameraChange`가 사용자 거리 저장 및 자동 추적 해제 |
| 러닝 중/일시정지 | 기존 거리 및 세로 오프셋 기반 자동 추적 유지 |

## 세부 작업

- [x] 최초 카메라 거리 정책을 분리하고 단위 테스트를 추가한다.
- [x] 첫 위치 수신 및 `onAppear` 초기 보정에 정책 값을 적용한다.
- [ ] Debug iOS Simulator 빌드 및 전체 iPhone 단위 테스트를 실행한다.
- [ ] 실기기에서 최초 진입·내 위치 버튼·수동 줌/이동·앱 재진입을 QA한다.

## 완료 기준

- 최초 진입이 내 위치 버튼을 누른 화면과 같은 약 1,000m 범위로 표시된다.
- 사용자의 수동 줌/이동과 러닝 상태별 자동 추적에 회귀가 없다.
- 지도 스타일, 핀/경로 렌더링 및 위치 권한 흐름은 변경하지 않는다.
