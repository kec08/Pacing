# App Store 심사 대응: 나이 정보 제거 계획

## 배경

App Store 심사(Guideline 5.1.1(v))에서 앱 핵심 기능과 직접 관련 없는 나이 정보의 필수 수집이 지적되었습니다.

## 목표

- 신규 사용자가 나이를 입력하거나 저장하지 않도록 한다.
- 프로필 편집에서 나이 항목을 제거한다.
- 로컬 저장소와 Firestore의 나이 읽기·쓰기 경로를 제거한다.
- 기존 사용자의 Firestore 나이 필드는 다음 프로필 저장 또는 로그인 복원 시 삭제한다.

## 변경 범위

1. 온보딩의 나이 Picker와 상태를 제거하고 진행 단계를 1단계 축소한다.
2. 프로필 편집 UI와 ViewModel의 나이 검증·상태·저장 파라미터를 제거한다.
3. Firestore 프로필 저장 API에서 나이 파라미터를 제거하고, 저장 시 기존 `age` 필드를 삭제한다.
4. 인증 복원 및 로그아웃/탈퇴 시 UserDefaults의 기존 `age` 키를 정리한다.

## 검토 결과

- 나이는 러닝 기록, 페이스 계산, 친구 기능, 음악 추천의 입력값으로 사용되지 않는다.
- 사용자 수정 파일(`project.pbxproj`, `Pacing.entitlements`)은 이번 작업에서 변경하지 않는다.
- 기존 계정의 데이터 정리는 앱이 해당 프로필을 복원하거나 저장할 때 수행하므로, 별도 서버 마이그레이션 없이 앱 범위 내에서 안전하게 처리할 수 있다.

## QA 기준

- 신규 가입 온보딩에 나이 입력 화면이 노출되지 않는다.
- 프로필 편집에 나이 필드 및 나이 유효성 오류가 없다.
- 앱 코드에 `age` 프로필 읽기·쓰기 경로가 남지 않는다(레거시 Firestore 필드 삭제 처리 제외).
- 빌드와 기존 단위/UI 테스트가 성공한다.
