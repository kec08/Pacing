# #193 워치 콘텐츠 동기화 및 최근 러닝 상세 최종 보고서

## 개요

워치가 아이폰 앱 실행 여부에 따라 최근 러닝·음악 정보를 잃는 문제를 해결했다. 워치는 한 번 동기화한 콘텐츠를 로컬에 보관해 즉시 표시하며, 연결이 복구되면 최신 기록으로 갱신한다. 이전 운동 상태가 워치의 정지 화면을 잘못 표시하던 문제도 함께 차단했다.

## 변경 사항

- 최근 러닝 기록과 음악 재생 스냅샷을 워치 로컬 저장소에 보관하고 앱 시작 시 복원한다.
- 워치 활성화 및 최근 러닝 화면 진입 시 아이폰에 최신 러닝 기록을 요청한다.
- 즉시 연결할 수 없을 때는 WatchConnectivity 백그라운드 전달 큐로 기록·음악 갱신 요청을 보존한다.
- 아이폰은 워치의 기록 갱신 요청을 받으면 Firestore에서 최신 기록을 조회해 다시 발행한다.
- `applicationContext`에 남은 과거 운동 상태는 워치 러닝 UI에 적용하지 않는다. 실시간 운동 스냅샷이 유효할 때만 러닝 탭으로 이동한다.
- 최근 러닝 상세에 칼로리와 케이던스를 추가했다. 케이던스 값이 없는 과거 기록도 항목을 유지하고 `--`로 표시한다.

## 기술적 고려 사항

- 지속해야 하는 콘텐츠(러닝 이력·음악)와 일시적인 운동 세션 상태를 분리했다. 이로써 콘텐츠는 오프라인에서도 복원되지만, 종료된 운동의 정지 상태는 재실행 시 복원되지 않는다.
- 칼로리는 아이폰의 기존 러닝 상세와 동일하게 저장된 몸무게와 거리로 계산해 동기화한다.
- 칼로리는 선택값으로 모델링해, 이전 형식으로 저장된 워치 캐시도 디코딩 실패 없이 유지한다.

## 남은 이슈

자동화된 시뮬레이터 테스트 환경은 현재 사용할 수 없어, WatchConnectivity의 실제 전달 타이밍과 백그라운드 갱신은 실기기에서 최종 확인이 필요하다.
