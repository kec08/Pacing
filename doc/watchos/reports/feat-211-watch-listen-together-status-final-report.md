## 구현 요약

Apple Watch 세 번째 같이 듣기 탭을 iPhone의 실제 같이 듣기 세션과 연결했습니다. 세션이 없을 때는 iPhone에서 시작하도록 안내하고, 활성 세션에서는 앨범 아트·곡 정보·참여자 역할·함께 들은 시간을 Watch 화면에 맞게 표시합니다.

러닝 중에는 현재 사용자의 역할을 함께 전달합니다. 호스트는 기존 음악 제어 탭을 유지하고, 게스트는 재생 제어 없이 같이 듣기 상태 화면을 표시합니다.

## 변경 사항

- iPhone→WatchConnectivity 같이 듣기 스냅샷과 Watch 캐시·최신성 검증 추가
- 앨범 아트 축소 데이터 및 URL, 참여자 프로필·이름·호스트/게스트 역할·시작 시각 전달
- 활성 세션의 제목·아티스트·둥근 앨범 아트·참여자 가로 행 UI 추가
- 비활성 상태의 iPhone 유도 문구 및 아이콘 유지
- 역할별 제어 권한 전달: 러닝 중 호스트는 음악 제어 탭, 게스트는 상태 전용 탭 사용
- 호스트 역할 텍스트를 앱 메인 핑크 색상으로 표시
- 경과 시간을 `TimelineView` 갱신 시각으로 계산해 초/분 단위로 실시간 반영
- 앨범 정보 카드 배경 제거, 하단 탭 표시와 참여자 행이 겹치지 않도록 여백 보정
- 음성 안내 중 게스트 재생 위치 보정을 보류하고 안내 종료 후 최신 호스트 위치로 재동기화

## 기술적 고려 사항

- 재생 위치 변화만으로 앨범·프로필 이미지를 반복 전송하지 않도록 스냅샷 내용을 비교해 중복 발행을 막았습니다.
- 전송량 제한에 가까워질 때는 프로필 이미지부터 제외하고 앨범 아트는 유지합니다.
- Watch의 마지막 스냅샷을 저장해 연결이 늦어도 최근 상태를 복원하며, 종료 상태 역시 저장해 종료된 세션이 다시 나타나지 않게 합니다.
