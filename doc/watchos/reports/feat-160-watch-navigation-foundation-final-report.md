## 구현 요약

Pacing Apple Watch 앱의 첫 공통 화면 기반을 구성했다. 4개 페이지를 좌우 스와이프로 이동하며, 앱을 열면 러닝 탭이 기본으로 선택된다. 각 기능의 실제 데이터·운동 측정은 후속 단계로 남기고, 실기기에서 확인 가능한 화면 구조와 초기 상태 UI를 우선 구현했다.

## 구현된 기능 목록

- [x] 음악, 러닝, 같이 듣기, 활동의 4페이지 네비게이션
- [x] 러닝 탭 기본 선택 및 하단 점 인디케이터 직접 선택
- [x] Pacing 투명 로고를 활용한 중앙 러닝 시작 조작
- [x] 활동 탭의 이번 달 거리·러닝 횟수 요약 및 최근 러닝 빈 상태
- [x] Pacing 다크 테마, 좁은 좌우 여백, 작은 카드 모서리 반경 적용
- [x] VoiceOver용 탭·러닝 시작 접근성 문구 적용
- [x] `ObservableObject`/`@Published`용 `Combine` import 보완
- [ ] HealthKit 운동 세션·GPS·실시간 거리/페이스 (후속 이슈)
- [ ] Apple Music·같이 듣기·Firebase/WatchConnectivity 실제 연동 (후속 이슈)

## 알려진 제한사항

- 중앙 Pacing 로고 탭은 아직 HealthKit 운동 세션을 생성하지 않고 준비 안내만 표시한다.
- 활동 탭의 거리·횟수·최근 러닝은 디자인 검증용 초기값이며 실제 기록을 조회하지 않는다.
- 음악·같이 듣기 탭은 빈 상태 UI만 제공한다.
- 전체 프로젝트 빌드는 의존성 네트워크 접근이 가능한 환경에서 한 번 더 확인해야 한다.
