## 구현 요약

iPhone MusicKit의 앨범아트와 재생 상태를 WatchConnectivity로 안정적으로 전달하도록 개선했습니다. Watch 러닝 음악 화면에는 확대 가능한 앨범아트, 현재 iPhone에서 재생 중인 플레이리스트 전체 목록, 고정된 목록/닫기 버튼을 제공하며, iPhone 조작과 Watch 화면의 곡·재생 상태가 빠르게 일치하도록 동기화 경로를 보강했습니다.

## 변경 사항

- iPhone에서 축소 JPEG 앨범아트를 생성해 현재 곡과 플레이리스트 곡별로 Watch에 전달
- `musicKit://` URL 의존을 제거하고 `Data → HTTP(S) URL → placeholder` 순서로 렌더링
- payload 크기를 제한하고 이미지 전송 실패 시 메타데이터·재생 제어가 유지되도록 fallback 처리
- 현재 iPhone 재생 큐의 전체 플레이리스트를 Watch 목록에 표시하고 곡 선택 재생 연결
- 이전/다음/재생·일시정지 명령의 Watch 낙관적 UI 반영 및 iPhone 최신 스냅샷 재동기화
- 앨범아트 모서리·확대 크기·제목/아티스트 위계·제어 버튼 크기 개선
- 플레이리스트/X 버튼을 상위 탭 레이어에 고정해 앨범 확대·목록 전환 중에도 위치 유지
- 플레이리스트 하단 여백을 제거해 탭 인디케이터 직전까지 목록 노출 영역 확장
- iPhone 러닝 종료 시 Watch 러닝 화면 즉시 종료 및 종료 스냅샷 재표시 방지
- iPhone 실행 스냅샷을 매번 Watch 타이머 기준점으로 적용해 경과 시간이 앞뒤로 튀는 현상 수정

## 계획서 대비 변경 사항

| 항목 | 계획 | 실제 구현 | 사유 |
|---|---|---|---|
| 앨범아트 전송 | 축소 JPEG·전송 예산 적용 | 완료 | WatchConnectivity payload 안정성 확보 |
| Watch 목록 | 최근 재생 목록 표시 | 활성 iPhone 플레이리스트 전체 표시·곡 선택 재생 | 실기기 사용성 피드백 반영 |
| 음악 UI | 앨범아트 표시 검증 | 확대 동작, 고정 버튼, 목록 노출 영역까지 개선 | 작은 Watch 화면의 조작성과 가독성 보강 |
| 동기화 | 앨범아트 중심 | 재생 상태·곡 전환·러닝 종료·경과 시간 동기화 보강 | 실기기 QA 중 확인된 연계 문제 해결 |
