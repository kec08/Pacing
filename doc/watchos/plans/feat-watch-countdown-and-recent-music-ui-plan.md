## 1. 목적 및 배경

Apple Watch에서 러닝 시작 시 3·2·1 카운트다운은 표시되지만, iPhone 앱의 숫자별 축소 상태에서 확대되는 전환 피드백과 일치하지 않는다. 또한 최근 재생한 음악 목록 우측의 현재 곡 상태 아이콘이 핑크색으로 강조되어 목록 탐색 UI에 불필요한 시각적 요소가 된다. 앨범 커버는 iPhone 동기화 데이터가 존재하는 경우에도 안정적으로 표시되는지 함께 점검하고, 이미지 우선순위를 명확히 한다.

## 2. 사용자 시나리오

```text
사용자가 Watch에서 러닝 시작을 누르면
→ 3, 2, 1이 각각 작은 크기에서 자연스럽게 커지며 표시되고
→ 카운트다운이 끝나면 러닝 대시보드로 전환된다.

사용자가 Watch의 음악 탭을 열면
→ 최근 재생한 음악마다 전달된 앨범 커버가 표시되고
→ 우측의 핑크색 재생/정지 상태 아이콘 없이 곡 정보와 커버에 집중할 수 있다.
```

## 3. 변경 범위

### Watch 카운트다운

- 대상: `WatchRunningTabView`
- iPhone `RunningView`의 카운트다운 패턴을 기준으로, 숫자가 변경될 때마다 축소값으로 즉시 초기화한 뒤 확대 애니메이션을 수행한다.
- Reduce Motion이 활성화되면 크기 애니메이션을 생략한다.
- 기존 3초 타이머, HealthKit 세션 시작 시점, Watch↔iPhone 시작 명령 흐름은 변경하지 않는다.

### 최근 재생 음악

- 대상: `WatchMusicTabView`, `WatchMusicArtwork`
- 최근 재생 행 우측의 현재 곡 재생/정지 상태 SF Symbol 및 핑크색 강조를 제거한다.
- 앨범 커버는 수신한 축소 이미지 데이터 우선, 유효한 HTTP(S) URL 차선, 기본 음악 아이콘 최후 순서로 표시되는 기존 경로를 검증하고 필요한 최소 보완을 한다.
- 곡을 탭해 iPhone 재생 명령을 보내는 동작과 접근성 레이블은 유지한다.

- [ ] 카운트다운 후 운동 시작 및 iPhone 동기화 시점이 기존과 동일하다.
- [ ] 최근 재생 목록 오른쪽에 핑크색 정지/재생 아이콘이 표시되지 않는다.
- [ ] 최근 재생한 곡은 유효한 이미지 데이터 또는 HTTP(S) artwork URL이 있으면 앨범 커버를 표시하며, 없으면 기본 아이콘으로 안전하게 대체된다.
- [ ] Watch 단위 테스트 및 빌드를 통과하고, 실기기 QA 결과를 이슈와 최종 보고서에 기록한다.

## 6. 기술 검토

- iPhone의 `.id(cd)`와 `countdownScale` 조합은 숫자 변경마다 새 뷰를 만들고 축소→확대를 시작한다. Watch에도 동일한 상태 전환 원칙을 적용하되, 화면 크기에 맞는 작은 숫자 크기와 짧은 easing을 사용한다.
- 앨범 커버 전송은 기존 #180 대응 경로가 담당한다. 이번 변경은 해당 동기화 계약을 넓히지 않으며, Watch 뷰에서 이미지를 숨기는 레이아웃 문제가 없는지 확인하는 범위로 제한한다.
- 기존 워킹 트리의 Xcode 프로젝트·빌드 산출물 변경은 사용자 소유로 간주하며 수정하거나 커밋하지 않는다.

## 7. 검증 계획

1. Preview/단위 테스트에서 Watch ViewModel의 카운트다운 상태가 3→2→1을 유지하는지 확인한다.
2. Watch 앱 빌드 후 Simulator에서 숫자별 확대 전환과 최근 목록 레이아웃을 확인한다.
3. 실기기에서 iPhone과 Watch를 연결해 최근 재생 곡의 이미지 데이터, HTTP(S) artwork fallback, artwork 없음 상태를 각각 확인한다.
4. 실기기에서 Watch 시작 카운트다운과 iPhone 시작 동기화, 곡 탭 재생 명령을 확인한다.

## 8. 보완 사항 (2026-09-29)

- 러닝 경험 화면을 표시하기 전에 Watch의 선택 탭을 대시보드로 확정해 기본 시작 버튼이 잠깐 보이는 전환을 제거한다.
- 러닝 시작 전 첫 음악 탭의 최근 재생 목록에도 축소 JPEG artwork data를 포함한다. 이전 구현은 현재 곡과 러닝 중 재생 목록만 artwork data를 우선 전달해, 첫 탭의 `musicKit://` URL이 기본 이미지로 대체될 수 있었다.
- 최근 재생 곡의 시스템 플레이어 ID를 현재 큐의 `Song.ID`로 정규화해, 러닝 중 플레이리스트와 동일하게 Watch 탭 재생 명령이 iPhone 큐를 찾도록 한다. 현재 재생 곡은 우측 볼륨 아이콘으로 표시한다.
- Watch가 선택한 최근 재생 곡의 제목·아티스트도 iPhone으로 전달한다. 현재 큐에 없는 곡은 카탈로그 ID 또는 제목·아티스트로 해석해 단일 재생 큐를 구성한다. 볼륨 아이콘은 iPhone이 실제 전환 후 발행한 스냅샷에서만 이동한다.
- `musicKit://` artwork URL은 Watch가 직접 다운로드할 수 없으므로, 러닝 중 플레이리스트의 현재 곡 인접 항목도 HTTP(S) artwork URL을 우선 해석해 축소 JPEG를 재발행한다.
