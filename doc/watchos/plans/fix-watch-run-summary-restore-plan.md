# fix: Watch 러닝 종료 요약 화면 복구 계획서

> **상태**: 검토 완료 · 구현 진행 예정  
> **작성일**: 2026-09-29  
> **기준 브랜치**: `dev`

## 목적

러닝 종료 후 Watch가 `WatchRunSummaryView`를 표시하지 않고 즉시 홈으로 돌아가는 회귀를 복구한다. 이미 종료된 과거 iPhone 스냅샷이 Watch 앱 재실행 시 홈을 덮어쓰지 않도록 한 기존 보호 로직은 유지한다.

## 작업 범위

- iPhone 종료 명령과 종료 스냅샷 처리에서 `WatchRunningState.ended`를 즉시 `idle`로 초기화하지 않는다.
- 종료된 HealthKit 세션 정리 완료 후에도 종료 요약용 metrics를 유지한다.
- 사용자가 요약 화면의 완료를 탭할 때만 `reset()`하여 홈으로 복귀한다.
- 유휴 상태에서 이전 종료 스냅샷을 받으면 요약 화면을 다시 열지 않는 기존 방어 로직을 유지한다.

## 검증

1. Watch에서 종료: 종료 요약·거리·페이스·완료 버튼을 확인한다.
2. iPhone에서 종료: Watch가 동일한 종료 요약으로 전환되는지 확인한다.
3. Watch 앱 재진입: 과거 종료 스냅샷으로 요약이 다시 열리지 않는지 확인한다.
4. Watch Simulator 테스트·빌드 및 실기기 빌드를 실행한다.
