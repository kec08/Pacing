# Watch 같이 듣기 상태 화면 계획서

관련 이슈: [#211](https://github.com/kec08/Pacing/issues/211)

## 목표

Apple Watch 세 번째 같이 듣기 탭에서 iPhone의 실제 같이 듣기 세션을 표시한다. 비활성 상태는 iPhone 유도 안내를, 활성 상태는 iPhone 시트의 곡·참여자 정보를 Watch에 맞춘 가로 행으로 제공한다.

## 구현 범위

- iPhone에서 세션 상태, 제목·아티스트, 앨범 아트 URL·축소 JPEG, 시작 시각, 참여자·역할을 `PhoneListenTogetherSnapshot`으로 발행한다.
- 세션 활성화·곡 변경·종료 시만 WatchConnectivity 스냅샷을 갱신하며, 재생 위치 변화에는 중복 전송하지 않는다.
- 앨범 아트는 URL 우선 렌더링과 축소 JPEG 보조 데이터를 함께 사용한다. 전송량 부족 시 프로필 이미지부터 제거하고 앨범 아트는 유지한다.
- Watch는 최신 스냅샷을 캐시하고 종료 상태도 저장해 과거 활성 세션이 재표시되지 않게 한다.
- 활성 UI에는 둥근 앨범 아트, 곡 제목·아티스트, 원형 참여자 프로필·이름·호스트/게스트 배지·함께 들은 시간을 표시한다.
- 비활성 UI는 기존 그룹 아이콘과 “iPhone에서 친구와 같이 듣기를 시작해 보세요.” 안내를 표시한다.

## 제외 범위

- Watch에서 요청 보내기·수락·거절·종료 제어
- Watch 단독 Apple Music 재생
- iPhone 같이 듣기 시트 UI 변경

## 검증

- 스냅샷 인코딩/디코딩, 역할, 앨범 아트 보존, 비활성 상태 단위 테스트
- iPhone 및 watchOS 빌드, `git diff --check`
- 실기기에서 시작·곡 변경·종료와 앨범 아트 표시, 다크 모드·Dynamic Type·연결 지연을 확인
