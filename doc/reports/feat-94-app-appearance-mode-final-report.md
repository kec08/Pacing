## 구현 요약

앱 전체에 시스템 설정·라이트·다크 화면 모드를 도입했다. 최초 기본값은 라이트 모드이며, 사용자가 변경한 값은 기기에 저장된다. 기존 의미론적 색상 토큰을 동적 팔레트로 전환해 주요 화면 및 MapKit 지도에 일관되게 반영했다.

## 구현된 기능 목록

- [x] `AppAppearance` 모델과 `AppState` 기반 영속 상태
- [x] 루트 화면의 동적 `preferredColorScheme` 적용
- [x] Figma 참조 기반 다크 표면·텍스트·구분선·상태 색상 토큰
- [x] 마이 탭의 `화면 모드 변경` 진입 행
- [x] 시스템/라이트/다크 모드 미리보기 및 단일 선택 화면
- [x] 러닝 중 지도, 요약, 활동 상세, 경로 썸네일의 전역 모드 상속
- [x] 러닝 화면 내부에 남아 있던 라이트 모드 강제 설정 제거

## 계획서 대비 변경 사항

| 항목 | 계획 | 실제 구현 | 사유 |
|------|------|-----------|------|
| 지도 다크 처리 | 지도별 스타일 적용 | 전역 색상 환경을 모든 SwiftUI Map이 상속 | 시스템·라이트·다크 선택 전환을 즉시 일관되게 반영 |
