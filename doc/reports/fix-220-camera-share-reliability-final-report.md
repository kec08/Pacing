## 구현 요약

러닝 기록 사진 공유에서 첫 공유 시 이미지가 누락될 수 있던 상태 의존성을 제거하고, 촬영 화면에 전·후면 카메라 전환을 추가했다. iOS 26 및 Swift 6 전환 과정에서 발견된 API·동시성·미사용 코드 경고도 함께 정리했다.

## 구현된 기능 목록

- [x] 공유 이미지가 준비된 뒤에만 시트를 여는 식별 가능한 공유 페이로드 구조 적용
- [x] 일반 공유 이미지와 Instagram Story 1080×1920 이미지를 활동 대상에 맞게 제공
- [x] 전·후면 카메라 입력 장치 전환 및 촬영 중 전환 비활성화
- [x] 촬영 버튼 중앙 정렬, 전환·닫기 버튼의 최종 위치 및 접근성 레이블 반영
- [x] FCM 등록 API 시그니처, iOS 26 화면 스케일·역지오코딩, Swift 동시성 관련 경고 정리

## 계획서 대비 변경 사항

| 항목 | 계획 | 실제 구현 | 사유 |
|------|------|-----------|------|
| 위치 변환 | iOS 26 MapKit 전환 및 이전 OS 대응 | iOS 26은 MapKit 사용, 이전 OS는 기본 안내 문구 표시 | deprecated `CLGeocoder`를 유지하지 않고 경고 없는 경로로 단순화 |
| 카메라 전환 UI | 전환 제어 추가 | 촬영 버튼 오른쪽 순환 화살표 버튼으로 배치 | 실기기 피드백에 따른 사용성 조정 |

## 알려진 제한사항

- iOS 26 미만에서는 deprecated API를 사용하지 않으며 공유 카드에 `위치 정보 없음`을 표시한다.
- 실제 카메라 장치 전환 및 Instagram 앱 수신 결과는 실기기에서 확인해야 한다.
- 전체 스킴 빌드는 이번 변경과 무관한 WatchKit 모듈·Watch 자산 카탈로그 환경 문제를 먼저 해결해야 완료할 수 있다.
