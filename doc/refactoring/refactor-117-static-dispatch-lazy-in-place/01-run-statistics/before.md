# Before — 주간·친구 프로필 러닝 통계

## 병목

기존 구현은 주간 기록을 `filter`로 새 배열에 복사한 뒤, 유효 페이스 기록을 다시 `filter`로 복사했다. 이후 거리·시간·유효 거리·유효 시간을 각각 `reduce`로 계산해 동일 데이터를 여러 번 순회했다.

## 측정 조건

- 입력: 러닝 기록 100,000개
- 컴파일: `swiftc -O`
- 반복: 30회 × 5샘플
- 네트워크·Firebase·UI 렌더링 제외
