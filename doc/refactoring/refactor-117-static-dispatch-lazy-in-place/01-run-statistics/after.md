# After — 주간·친구 프로필 러닝 통계

## 변경

`RunStatisticsCalculator`에서 `lazy` 단일 순회로 거리·시간·유효 페이스 값을 동시에 누적한다. 홈 주간 통계와 친구 프로필 통계가 같은 계산기를 사용한다.

## 결과

| Before | After | 개선율 |
| ---: | ---: | ---: |
| 0.52980 ms ±0.02245 | 0.08672 ms ±0.00780 | 83.6% |

Before/After checksum이 일치했다.
