# Before — 러닝 경로 경계 계산

## 병목

러닝 상세·요약·썸네일 화면이 각각 경로 좌표에서 위도와 경도를 별도 배열로 복사한 뒤 `min`·`max`를 계산했다. 좌표 수가 늘어날수록 배열 할당과 반복 순회가 누적됐다.

## 측정 조건

- 입력: 경로 좌표 100,000개
- 컴파일: `swiftc -O`
- 반복: 30회 × 5샘플
- Map 렌더링과 카메라 애니메이션 제외

## 기준선

| 항목 | 평균 | 표준편차 |
| --- | ---: | ---: |
| 경로 경계 계산 | 0.80428 ms | ±0.01138 ms |
