# After — 러닝 경로 경계 계산

## 변경

`RunRouteBounds`에서 첫 좌표를 기준으로 최소·최대 위도와 경도를 한 번만 순회하며 직접 변경한다. 상세·요약·썸네일 화면은 공통 계산기를 사용한다.

## 결과

| Before | After | 개선율 |
| ---: | ---: | ---: |
| 0.80428 ms ±0.01138 | 0.09730 ms ±0.00509 | 87.9% |

Before/After checksum이 일치했다.

## 포트폴리오 요약

좌표 배열 복사와 다중 순회를 제거해 100,000개 좌표의 경로 경계 계산 시간을 **87.9% 개선**하고, 세 화면의 동일 로직을 하나로 통합했다.
