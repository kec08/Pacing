# After — Sub-sequence Sharing

필요한 배치 범위만 `ArraySlice`로 생성해 원본 `tracks` 버퍼를 공유하며 순회한다. 배치 배열 목록과 각 배치의 복사를 제거했다.

릴리스 최적화(`-O`)로 100,000개 `TrackPayload`를 4개씩 나누고, 각 배치의 모든 ID·제목·아티스트를 실제로 읽는 벤치마크를 세 번 독립 실행했다. 중앙값은 `2.75048 ms → 0.21707 ms`로, **92.1% 개선**이다.

기존 99.9% 수치는 배치의 `count`만 합산해 컴파일러가 after 반복을 과도하게 최적화할 여지가 있어 폐기했다. 이 값은 배치 배열 25,000개 복사를 없앤 계산 구간의 효과이며, 실제 MusicKit 네트워크 요청 시간은 포함하지 않는다.
