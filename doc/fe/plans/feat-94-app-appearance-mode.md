# 앱 화면 모드(시스템·라이트·다크) 적용 계획서

> **상태**: 검토 완료 · 개발 진행 승인
> **작성일**: 2026-08-09
> **관련 이슈**: #94
> **브랜치**: `feat/94-app-appearance-mode`

---

## 1. 목적 및 배경

사용자가 앱의 화면 모드를 시스템 설정, 라이트 모드, 다크 모드 중 직접 선택할 수 있게 한다. 기본값은 라이트 모드이며, 선택은 앱을 재실행해도 유지된다. 기존 디자인 토큰을 동적 색상으로 전환해 모든 앱 화면과 지도에 일관되게 반영한다.

## 2. 사용자 시나리오

```
사용자가 마이 탭의 “화면 모드 변경”을 누르면
→ 시스템 설정 / 라이트 모드 / 다크 모드 선택 화면으로 이동하고
→ 한 항목을 선택하면 즉시 앱 전체와 지도 표시가 변경되며
→ 다음 앱 실행에서도 같은 선택이 유지된다.
```

## 3. 화면 구성

### 주요 화면
- 마이 탭: 로그아웃 상단에 `화면 모드 변경` 행을 추가한다.
- 화면 모드 설정: 참조 이미지처럼 각 모드의 미리보기, 제목, 시스템 모드 설명, 단일 선택 표시를 제공한다.

### UI 요소
- `AppAppearance`: 시스템/라이트/다크 모드 및 화면 제목을 제공하는 모델.
- `AppearanceSettingsView`: 설정 선택 화면. 선택 행은 최소 44pt 터치 영역과 VoiceOver 상태를 제공한다.
- 동적 색상 토큰: 라이트·다크 배경, 텍스트, 회색, 구분선 색상을 환경 색상 모드에 맞춰 제공한다.

## 4. 데이터 흐름

### 사용 데이터
- 외부 API/DB 변경 없음.
- `UserDefaults`: `appAppearance` 키에 선택값을 저장한다.

### 상태 관리
- `AppState`: 선택 모드 저장·복원 및 `preferredColorScheme` 변환을 담당한다.
- `PacingApp`: `AppState`의 선호 색상 모드를 루트 환경에 적용한다.
- 개별 View: 기존 의미론적 색상 토큰을 그대로 사용하여 자동 전환된다.

## 8. 특이 사항 / 기술 검토

- 참조 이미지의 다크 팔레트 의도에 맞춰 표면은 `#151515`/`#202020`, 본문은 고대비 흰색 계열, 보조 텍스트는 회색 계열을 사용한다. 브랜드 핑크·인디고와 상태 색상은 식별성을 유지한다.
- SwiftUI `Map`은 루트의 `preferredColorScheme` 및 명시적 `MapStyle`을 함께 사용한다. 실제 지도 타일의 세부 표현은 iOS/지도 데이터에 따라 다를 수 있다.
- 기존의 직접 지정된 흰색·검정색 일부는 시스템 색상으로 교체해 대비를 보장한다.
