# Apple Music 전체 플레이리스트·재생 제어·곡 상태 동기화 수정 계획서

> **상태**: 승인 완료  
> **작성일**: 2026-08-18  
> **관련 이슈**: #115  
> **브랜치**: `fix/115-apple-music-playback-sync`

---

## 목적

Apple Music 보관함 플레이리스트 전체 조회, 선택한 플레이리스트의 전체 곡(커버·제목·아티스트) 표시, 실제 재생 큐 제어, 홈·러닝·음악 탭의 현재 곡 상태 일치를 구현한다.

## 성능 원칙

- 플레이리스트 메타데이터는 전체 조회하되 임의 개수로 자르지 않는다.
- 수록곡은 사용자가 선택한 단일 플레이리스트만 조회한다.
- 커버는 화면에 표시되는 행에서 지연 로드하고 캐시하며, 플레이리스트 전환 시 이전 요청 결과를 무시한다.
- 곡 행 선택은 이미 준비한 재생 큐를 이용해 즉시 실행한다.

## 작업 및 완료 기준

- [ ] 전체 플레이리스트가 표시된다.
- [ ] 선택한 플레이리스트의 모든 곡에 커버·제목·아티스트가 표시되고 곡 행 선택 재생이 된다.
- [ ] 이전·재생/일시정지·다음 제어가 실제 큐에 동작한다.
- [ ] 다크 모드 미니 플레이어의 다음 버튼 대비가 충분하다.
- [ ] 홈·러닝·음악 탭의 현재 곡 제목·아티스트·커버가 일치한다.
- [ ] 빌드 및 Apple Music 실기기 QA를 진행한다.
