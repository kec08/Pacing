## 1. 목적 및 배경

지도에서 내 프로필과 현재 재생 음악을 보여 주던 커스텀 핀이 사라졌다. 사용자가 원하는 것은 프로필 정보 핀의 제거가 아니라, 프로필 정보 없이 보이는 빨간 현재 위치 점의 제거다.

또한 Apple Music 추천 플레이리스트와 친구 최근 음악 일부에서 대표 커버가 누락된다. 원본 아트워크 URL이 없거나 요청에 실패하는 경우에도 보조 조회와 기본 커버를 통해 빈 이미지 영역 없이 표시한다.

홈 음악 카드는 재생 시 작은 아이콘 대신 앨범 커버 전체를 감싸는 어두운 레이어와 그림자, 얇은 5개 음파로 현재 재생 상태를 명확히 표현한다.

## 2. 사용자 시나리오

```
사용자가 러닝 지도를 열면
→ 내 프로필 사진·닉네임·재생 곡이 포함된 커스텀 핀을 확인한다
→ 프로필 정보가 없는 빨간 현재 위치 점은 보이지 않는다

사용자가 음악 탭과 홈을 보면
→ 추천/친구 음악의 대표 커버를 확인한다
→ 원격 이미지가 없거나 실패해도 기본 커버가 표시된다
→ 친구 음악 카드를 탭하면 커버 전체에 재생 레이어와 5개 음파가 표시된다
```

## 3. 화면 구성

- 러닝 지도: 내 커스텀 프로필·음악 핀을 복구하고 시스템/대체 위치 점은 숨긴다.
- 음악 탭 > 나만을 위한 추천 플레이리스트: 대표 커버를 우선 표시하고, 보조 아트워크 조회와 기본 커버를 제공한다.
- 홈 > 친구가 최근에 들은 음악: 앨범 커버 전체에 딤·그림자 레이어, 얇은 5개 음파를 재생 상태에서만 표시한다.

## 4. 데이터 흐름

- 내 지도 핀: `LocationManager.currentLocation`, 현재 재생 곡 스냅샷, 저장된 프로필 이미지.
- 추천 커버: MusicKit `Playlist.artwork` → 카탈로그/라이브러리 보조 URL → `RemoteArtworkView` 기본 커버.
- 친구 음악 커버: Firestore Base64 → 원격 URL → 기본 커버.
- 재생 상태: 홈의 `playingFriendSongID`로 카드별 오버레이를 단일 선택 상태로 관리한다.

## 7. 기술 검토

- 지도에는 `UserAnnotation`을 추가하지 않고 커스텀 `Annotation`만 사용해 위치 점과 프로필 핀을 분리한다.
- MusicKit 항목은 일부 응답에서 artwork가 비어 있을 수 있으므로, 기존 서비스의 URL 해석 로직을 재사용하거나 확장한다.
- 이미지 네트워크 실패는 재시도 가능한 캐시 로더와 즉시 표시되는 기본 커버로 UX를 보장한다.
