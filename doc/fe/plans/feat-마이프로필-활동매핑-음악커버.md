# feat 마이 프로필 활동 매핑·음악 커버 보강 계획서

> **상태**: 구현 진행 중
> **작성일**: 2026-07-31
> **관련 이슈**: #82
> **브랜치**: `feat/82-profile-activity-artwork`

## 목적

- 마이 화면의 거리 그래프에서 특정 막대(날짜/기간)를 선택하면, 차트 바로 아래에 해당 날짜의 실제 러닝 활동을 별도 영역으로 확인할 수 있게 한다.
- 내 프로필과 친구 프로필의 최근 들은 노래 커버를 안정적으로 표시한다.
- 친구 프로필에 최근 러닝 목록을 유지하고, 내 프로필에도 동일한 최근 러닝 흐름을 제공한다.
- 내·친구 프로필의 최근 들은 노래는 최대 5개까지만 노출한다.

## 사용자 흐름

1. 사용자가 마이 화면에서 그래프 막대를 탭한다.
2. 차트 바로 아래에 `2026년 7월 28일 화요일 러닝`처럼 선택 날짜를 제목으로 하는 별도 영역이 생성된다.
3. 해당 날짜에 여러 번 러닝했다면 기존 최근 활동과 동일한 가로 카드 UI로 모두 표시된다.
4. 같은 막대를 다시 탭하면 선택 영역이 사라지고, 다른 날짜를 탭하면 해당 날짜의 카드 목록으로 즉시 전환된다.
5. 프로필 화면에서는 최근 러닝과 최근 들은 노래를 확인한다.
6. 음악 커버는 저장 이미지, 원격 URL, Apple Music 카탈로그 보조 조회 순으로 가져오며 실패 시에도 기본 커버를 표시한다.

## 구현 범위

- `MyViewModel`: 차트 엔트리에 날짜 식별자를 추가하고, 선택된 날짜의 러닝 기록 및 선택 토글 상태를 계산한다.
- `MyView`: `Chart` 선택 제스처 및 접근성 동작을 추가하고, 차트 바로 아래에 선택 날짜 전용 활동 카드 영역을 렌더링한다.
- `MyProfileDetailView`: 최근 러닝 섹션과 최근 음악 5개 제한을 추가한다.
- `MyProfileDetailViewModel`, `FriendProfileViewModel`: 최근 러닝·음악 로딩과 아트워크 URL 보강 상태를 분리 관리한다.
- `FriendProfileView`: 최근 음악을 최대 5개로 제한하고 보강된 커버 URL을 우선 표시한다.
- `AppleMusicRecommendationService`: 최근 음악의 제목·아티스트 기반 대표 커버 조회 로직을 재사용한다.

## 완료 기준

- 그래프의 각 막대를 탭하면 차트 바로 아래에 선택 날짜 전용 영역이 나타난다.
- 같은 막대를 다시 탭하면 선택 영역이 사라진다.
- 다른 막대를 탭하면 제목과 카드 목록이 새 날짜로 전환된다.
- 선택된 날짜에 여러 기록이 있으면 모든 러닝 카드가 표시되고, 기록이 없으면 명확한 빈 상태가 표시된다.
- 내 프로필과 친구 프로필 모두 최근 러닝을 표시한다.
- 내·친구 프로필의 최근 음악은 최대 5개만 표시된다.
- 저장 아트워크가 없는 최근 음악도 보조 URL 또는 기본 커버가 표시되어 빈 이미지 영역이 없다.

## 검토 메모

- 그래프 선택은 `chartXSelection` 또는 오버레이의 좌표 변환으로 구현한다. 동일 날짜 재선택 시 해제하고, 다른 날짜 선택 시 교체하며, 기간 필터 변경 시 선택 상태를 초기화한다.
- 보조 카탈로그 조회는 아트워크가 없는 항목에 한정하고 결과를 캐시해 불필요한 요청을 줄인다.
- 기존 프로필/친구 화면의 카드 UI를 재사용해 화면 간 정보 구조를 일관되게 유지한다.
