# Pacing 이메일 로그인·회원가입 및 심사 접근성 개선 계획서

> **상태**: 진행 중
> **작성일**: 2026-07-20
> **관련 이슈**: #59
> **브랜치**: `feat/59-pacing-email-auth`

## 목적

Apple 로그인 오류와 심사 계정 부재로 발생한 App Store Guideline 2.1(a) 리젝에 대응한다. 소셜 로그인과 독립적으로 이메일·비밀번호 기반 Pacing 로그인을 제공하고, 심사관이 전체 기능을 확인할 수 있도록 한다.

## 사용자 흐름

1. 로그인 화면에서 Apple 로그인 상단의 핑크색 `Pacing으로 로그인`을 선택한다.
2. 이메일과 비밀번호로 로그인하거나 `회원가입`으로 이동한다.
3. 신규 가입자는 기존 4단계 프로필 설정(닉네임, 성별·나이, 키·체중, 프로필 사진)을 완료한다.
4. 프로필은 Firestore에 저장되고, 기존 사용자는 재로그인 시 바로 메인 화면으로 이동한다.

## 작업 범위

- 제공된 P 로고를 로그인 버튼 좌측 아이콘으로 추가
- 이메일 로그인·회원가입 화면 및 입력 검증 구현
- Firebase Authentication Email/Password 연동 및 오류 메시지 처리
- 가입 완료 후 기존 `ProfileSetupView` 재사용
- 유효성 검증 단위 테스트 및 Release 빌드 QA

## 완료 기준

- [ ] Pacing 로그인 버튼이 Apple 로그인보다 위에 표시된다.
- [ ] 기존 이메일 계정 로그인, 신규 계정 가입이 동작한다.
- [ ] 가입자는 닉네임·성별·나이·키·체중·프로필 사진을 입력한다.
- [ ] 프로필 저장 후 재로그인 시 프로필 입력을 반복하지 않는다.
- [ ] 심사 계정과 이용 절차를 App Store Connect에 등록한다.

## 사전 조건 및 제한 사항

- Firebase Console에서 Email/Password 제공업체를 활성화해야 한다.
- 심사 계정 자격 증명은 저장소가 아닌 App Store Connect에만 등록한다.
- Apple 로그인은 제거하지 않으며, capability 및 Firebase Apple provider 설정은 별도로 실기기 검증한다.
