# 홈 친구 활동 조회 및 지도 내 위치 추적 토글 수정 계획서

> **작성일**: 2026-08-18
> **관련 이슈**: [#113](https://github.com/kec08/Pacing/issues/113)
> **브랜치**: `fix/113-home-friend-activity-map-follow-toggle`

## 1. 목적

다른 계정으로 로그인했을 때 친구가 존재해도 홈의 `친구 최근 러닝`, `친구가 최근에 들은 음악` 전체가 오류 상태가 되는 문제를 해결한다. 또한 러닝 지도에서 내 위치 자동 추적 버튼을 단방향 활성화가 아닌 토글 방식으로 변경한다.

## 2. 원인 분석

### 친구 활동 조회

- `fetchFriendsRecentRuns`와 `fetchFriendsRecentSongs`가 친구 문서를 순차 조회한다.
- 친구 중 한 명의 `runHistory` 또는 `recentSongs` 읽기가 실패하면 `try`가 상위까지 전파된다.
- 홈 ViewModel은 이를 전체 목록 실패로 처리해, 접근 가능한 다른 친구 활동도 함께 표시하지 못한다.
- #111에서 적용한 프로필 공개 범위 규칙상 비공개 또는 현재 조회 권한이 없는 친구의 활동 조회가 실패할 수 있으므로 이 상황이 실제 전체 실패를 유발한다.

### 지도 내 위치 추적

- `focusOnMyLocation()`은 `isFollowingUser = true`만 수행한다.
- 이미 자동 추적 중인 상태에서 버튼을 다시 눌러도 해제 경로가 없다.
- 버튼의 접근성 문구도 항상 “추적 시작” 의미라 현재 상태와 맞지 않는다.

## 3. 구현 범위

### 홈 친구 활동

- 친구별 러닝·음악 조회 오류를 개별적으로 처리한다.
- 조회 권한이 없거나 읽기에 실패한 친구는 해당 섹션 결과에서 제외하고, 나머지 친구의 활동은 계속 표시한다.
- 친구 목록 자체 조회가 실패한 경우에만 기존 전체 오류 UI를 표시한다.
- 비공개 친구의 기본 프로필 정책은 유지하며, 활동 데이터는 홈에서 노출하지 않는다.
- 불필요하게 전체 요청을 중단하지 않도록 순차·병렬 처리 범위와 오류 로그를 점검한다.

### 지도 내 위치 추적 버튼

- 버튼 탭 동작을 아래처럼 변경한다.

| 현재 상태 | 탭 후 상태 | 동작 |
|---|---|---|
| 자동 추적 꺼짐 | 자동 추적 켜짐 | 현재 위치로 카메라 이동 후 이후 위치 업데이트를 추적 |
| 자동 추적 켜짐 | 자동 추적 꺼짐 | 카메라 위치 유지, 이후 위치 업데이트로 카메라를 이동하지 않음 |

- 활성/비활성 상태를 아이콘 색상·접근성 레이블·접근성 값으로 명확히 구분한다.
- 지도 드래그/확대 시 추적 해제하는 기존 동작과 충돌하지 않게 유지한다.
- idle·러닝·일시정지 상태에서 같은 토글 규칙이 적용되는지 확인한다.

## 4. 수정 대상

| 계층 | 대상 | 변경 내용 |
|---|---|---|
| Repository | `FirestoreService` | 친구별 활동 읽기 실패를 전체 실패로 전파하지 않도록 복구 처리 |
| ViewModel | `HomeViewModel` | 결과 없음과 전체 조회 실패 상태를 구분해 기존 오류 UI 유지 |
| View | `RunningView` | 내 위치 버튼을 추적 토글 액션과 상태별 접근성 표현으로 변경 |

## 5. QA 계획

| 시나리오 | 기대 결과 |
|---|---|
| 활동이 있는 공개 친구 + 비공개 친구 혼재 | 공개 친구의 러닝·음악만 표시, 전체 오류 카드 미표시 | 코드 검토 완료, 실기기 대기 |
| 모든 친구의 활동이 없음 | 오류 대신 기존 빈 상태 표시 | 코드 경로 확인 완료 |
| 친구 목록 조회 자체 실패 | 기존 오류 카드와 재시도 제공 | 기존 `throws` 경로 유지 확인 |
| 지도 추적 켜짐에서 버튼 탭 | 추적 해제, 이후 위치 이동에도 카메라 고정 | 코드 경로 확인 완료, 실기기 대기 |
| 지도 추적 꺼짐에서 버튼 탭 | 현재 위치로 이동 후 자동 추적 재개 | 코드 경로 확인 완료, 실기기 대기 |
| 지도 드래그/확대 | 자동 추적 해제 유지 | 기존 `stopFollowingUser()` 경로 유지 확인 |
