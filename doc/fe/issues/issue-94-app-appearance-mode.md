# #95 [feat] 앱 전체 화면 모드 설정 (시스템·라이트·다크)

> **유형**: Feature
> **작성일**: 2026-08-09
> **브랜치**: `feat/94-app-appearance-mode`
> **상태**: 개발 완료 · 검토 대기

## 개요

사용자가 마이 탭에서 시스템 설정, 라이트 모드, 다크 모드 중 앱 화면 모드를 선택할 수 있게 한다. 기본값은 라이트 모드이며, 선택값은 영속되고 MapKit 지도까지 같은 모드로 전환된다.

## 완료 기준

- [x] 기본값이 라이트 모드다.
- [x] 시스템/라이트/다크 모드를 단일 선택할 수 있다.
- [x] 선택 시 앱 전 화면과 지도가 즉시 전환된다.
- [x] 선택값이 앱 재실행 뒤에도 유지된다.
- [x] 참조 이미지의 다크 팔레트와 설정 목록 UX를 반영한다.
- [x] 접근성 레이블·선택 상태·최소 터치 영역을 제공한다.
