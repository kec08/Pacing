# #72 친구 플레이리스트 전체 커버 및 이미지 로딩 최적화 QA 보고서

> **상태**: 자동 검증 완료 / 실기기 QA 대기
> **브랜치**: `feat/72-music-artwork-performance`

## 변경 사항

- 목록은 대표 커버 1장만 보강해 초기 진입을 지연시키지 않는다.
- 상세와 내 플레이리스트 동기화는 누락된 모든 수록곡을 처리한다.
- 카탈로그 식별자 배치 조회 후 남은 곡은 최대 4개씩 병렬 검색한다.
- 동일 이미지 URL의 동시 요청을 병합하고, 80MB 메모리 캐시·120MB 디스크 캐시·720px 다운샘플링을 적용했다.
- 이미지 프리패치는 중복 URL 제거 후 최대 4개씩 병렬 실행한다.

## 자동 검증

| 항목 | 결과 |
|---|---|
| Swift 구문 검사 | ✅ `swiftc -parse` 통과 |
| 공백 오류 검사 | ✅ `git diff --check` 통과 |
| iOS Simulator Debug 빌드 | ✅ `xcodebuild ... build CODE_SIGNING_ALLOWED=NO` 통과 |

## 실기기 QA 요청

1. 친구 플레이리스트의 수록곡이 10곡 이상인 상세 화면을 연다.
2. 처음 진입 시 대표 커버가 빠르게 표시되는지 확인한다.
3. 스크롤 후 매칭 가능한 모든 수록곡에 개별 앨범 커버가 표시되는지 확인한다.
4. 상세를 닫고 다시 열어 이미지가 즉시 표시되는지 확인한다.
5. 네트워크를 끈 상태에서 플레이스홀더가 안전하게 유지되는지 확인한다.

## 제한 사항

- Apple Music 카탈로그에서 검색 결과가 없는 곡은 커버를 표시할 수 없어 플레이스홀더를 유지한다.
- `musicKit://` 전용 URL은 계속 차단하며, HTTP(S) 카탈로그 artwork만 이미지 로더가 처리한다.
