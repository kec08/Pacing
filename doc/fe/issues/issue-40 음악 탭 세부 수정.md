# [feat] 음악 탭 세부 수정

> **이슈 번호**: #40  
> **유형**: feature  
> **작성일**: 2026-07-14  
> **상태**: Open

## 개요

음악 탭 상세 화면과 친구 플레이리스트 재생 흐름의 완성도를 높입니다.

- 친구 플레이리스트 커버 이미지 fallback 보강
- 친구 플레이리스트 곡 탭 시 재생 실패 이슈 수정
- 상세 화면 하단 플레이리스트 버튼과 곡 목록 전환 UX 연결
- 좌상단 버튼으로 플레이리스트 선택 UI 진입 방식 변경
- 미니 플레이어 고정 노출 조건 점검 및 로딩 상태 최적화

## 사용자 문제

- 친구 플레이리스트에서 곡을 눌러도 재생이 시작되지 않는 경우가 있음
- 플레이리스트 커버가 비어 보이는 카드가 있음
- 상세 재생 화면 하단 플레이리스트 버튼이 실제 곡 목록과 연결되지 않음
- 로딩/상태 전환이 매끄럽지 않아 사용 흐름이 끊김

## 작업 범위

1. 친구 플레이리스트 재생 경로 점검 및 fallback 처리
2. 플레이리스트/트랙 커버 이미지 fallback 보강
3. 상세 화면 하단 플레이리스트 리스트 토글 구현
4. 리스트에서 곡 선택 시 해당 곡 재생 전환
5. 좌상단 플레이리스트 버튼 배치 및 기존 선택 시트 연결
6. 미니 플레이어 노출 조건 및 로딩 상태 정리

## 완료 기준

- [ ] 친구 플레이리스트 카드 및 상세에서 커버 이미지가 자연스럽게 표시된다
- [ ] 친구 플레이리스트 곡 탭 시 오류 없이 해당 곡 재생이 시작된다
- [ ] 하단 플레이리스트 버튼을 누르면 현재 보고 있는 해당 플레이리스트의 곡 목록이 리스트 형식으로 펼쳐진다
- [ ] 리스트에서 다른 곡을 선택하면 해당 곡으로 전환된다
- [ ] 좌상단 버튼으로 내 플레이리스트 선택 UI를 열고 닫을 수 있다
- [ ] 미니 플레이어가 실제 재생 상태 기준으로 일관되게 동작한다
- [ ] 로딩/빈 상태 전환이 기존보다 자연스럽다

## 구현 메모

- `SongView`, `SharedPlaylistDetailView`, `SongViewModel`, `SharedPlaylistDetailViewModel` 중심 수정
- MusicKit 라이브러리/카탈로그 ID 차이 가능성을 고려한 재생 처리 필요
- 배경 스타일은 유지하고 인터랙션과 정보 구조 위주로 개선
