# [feat] 러닝 활동 상세 및 경로·구간 페이스

> **상태**: GitHub 생성 보류
> **작성일**: 2026-07-17
> **브랜치**: `feat/run-activity-detail`

## 배경

홈의 최근 러닝과 마이페이지의 최근 활동은 상세 기록으로 진입할 수 없다.
사용자가 완료한 러닝의 경로와 km별 페이스를 확인할 수 있도록 공통 상세 화면이 필요하다.

## 구현 범위

- 활동 상세 화면: 거리, 시간, 평균 페이스, 칼로리 추정, 경로 지도
- km 구간별 페이스 화면
- 새 러닝의 km 랩 페이스 Firestore 저장 및 기존 기록 호환
- 홈·마이페이지의 공통 상세 진입

## 완료 기준

- [ ] 홈과 마이페이지의 최근 활동 카드가 동일한 상세 화면으로 이동한다.
- [ ] 경로 좌표가 있는 기록은 지도와 폴리라인을 표시한다.
- [ ] 경로·구간 데이터가 없는 기존 기록도 안전하게 표시한다.
- [ ] 새 러닝의 km 랩 페이스를 저장·조회한다.
- [ ] Debug 빌드 및 주요 사용자 흐름 QA를 통과한다.

## GitHub 연동 상태

GitHub App의 `kec08/Pacing` 이슈 생성 요청이 `403 Resource not accessible by integration`으로 거절됐다.
`gh auth status`도 저장된 인증 토큰이 유효하지 않다고 보고했다. 권한을 복구한 뒤 이 문서 내용으로 GitHub 이슈를 생성한다.
