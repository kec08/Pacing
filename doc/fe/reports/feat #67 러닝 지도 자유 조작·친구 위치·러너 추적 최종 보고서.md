## 구현 요약

러닝 지도에서 기존 카메라 거리 제한과 자동 스냅백을 제거하고, 사용자가 직접 지도를 조작할 때 자동 추적을 중지하도록 개선했습니다. 러닝 중 자동 추적이 활성화된 경우에는 내 위치를 부드럽게 따라가며, 지도에는 현재 러닝 중인 친구만 표시합니다.

## 구현된 기능 목록

### 1. 자유로운 지도 조작

- 지도 카메라 거리의 `100m~3,000m` 강제 제한을 제거했습니다.
- 드래그·핀치 조작 종료 후 자동으로 현재 위치로 되돌리는 스냅백 로직을 제거했습니다.
- 확대·축소 버튼도 동일한 강제 최대 거리 제한 없이 현재 줌 레벨을 기준으로 동작합니다.

### 2. 자동 추적 상태 관리

- 사용자가 지도를 드래그하거나 확대·축소하면 자동 추적을 해제합니다.
- 내 위치 버튼을 누르면 현재 줌 레벨을 유지한 채 자동 추적을 재개합니다.
- 러닝 시작 시 자동 추적을 활성화하고 현재 위치로 카메라를 맞춥니다.
- 위치 갱신에 따른 카메라 이동은 `easeInOut` 애니메이션으로 처리합니다.
- 프로그램 카메라 이동 중 MapKit 콜백이 수동 조작으로 오인되지 않도록 보호 시간을 적용했습니다.

### 3. 친구 위치 지도 표시

- `NearbyRunnerViewModel`에 `activeFriendRunners`를 추가했습니다.
- 실시간 러너 중 본인을 제외하고 친구 관계인 사용자만 지도 핀 목록에 포함합니다.
- 거리와 무관하게 현재 러닝 중인 친구를 지도에 표시합니다.
- 기존 주변 러너 시트의 친구/가까운 러너 필터 동작은 유지했습니다.
