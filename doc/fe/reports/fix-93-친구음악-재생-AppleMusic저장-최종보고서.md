## 구현 요약

친구가 듣고 있는 음악 영역의 카드·스켈레톤 레이아웃을 최근 앨범 UI와 통일하고, 친구 플레이리스트 목록의 조회·커버 보강 지연을 줄였다. 또한 재생 큐 전환 직후 첫 곡 표시가 사라지는 문제와 친구 플레이리스트가 Apple Music 보관함에 저장되지 않는 문제를 수정했다.

## 구현된 기능 목록

- [x] 친구 음악 카드와 스켈레톤의 앨범 카드 규격 통일
- [x] 친구별 Firestore 플레이리스트 조회의 제한 병렬 처리
- [x] 목록 최초 표시 뒤 대표 커버 보강 및 중복 요청 취소
- [x] 목록·상세의 첫 번째 수록곡 커버 일치
- [x] 전체 재생 시 첫 번째 곡 재생 상태 유지·동기화
- [x] 친구 플레이리스트의 Apple Music 보관함 생성 및 저장 상태 정합성
- [x] Firestore 기록 실패 후 재시도의 Apple Music 중복 생성 방지

## 계획서 대비 변경 사항

| 항목 | 계획 | 실제 구현 | 사유 |
|---|---|---|---|
| 목록 대표 이미지 | 유효 커버 보강 | 첫 수록곡 커버만 사용·보강 | 목록과 상세의 이미지를 반드시 동일하게 유지하기 위함 |
| 이미지 보강 시점 | 목록 표시 후 비동기 처리 | 동일하게 구현 | 초기 화면 지연 방지 |
| 저장 재시도 | 생성 식별자 기반 정책 | UserDefaults에 임시 생성 ID 보관 | Firestore만 실패해도 중복 생성되지 않도록 보장 |

## 알려진 제한사항

- Apple Music 보관함 생성과 실제 재생 이벤트는 활성 Apple Music 구독 계정이 로그인된 실기기에서 최종 확인해야 한다.
- 카탈로그에서 첫 수록곡을 찾을 수 없으면 다른 수록곡 이미지로 대체하지 않고 플레이스홀더를 유지한다. 이는 목록·상세 이미지 일치를 위한 의도된 정책이다.

## 다음 단계 / 후속 작업

- 다른 앨범 재생 후 친구 플레이리스트 전체 재생 시 첫 곡 강조, 자동 다음 곡 강조를 확인한다.
