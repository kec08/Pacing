## 1. 구현 요약

같이 듣기 세션에서 호스트와 게스트의 곡, 재생 위치, 재생 상태, 지도 표시, 앨범 커버가 동일한 세션 스냅샷을 기준으로 동작하도록 수정했다. 게스트 음악 시트는 같이 듣기 시트와 동일한 커버 표시 경로를 사용하며, 일반 음악 시트의 앨범 드래그 기능은 유지하도록 표시 분기를 정리했다.

## 2. 변경 사항

- 호스트의 현재 곡과 재생 상태를 세션 기준으로 브로드캐스트하고 게스트가 동일한 곡을 재생하도록 보정
- 호스트의 재생·일시정지·시크 위치를 게스트에 동기화
- 게스트가 로컬에서 일시정지할 수 있도록 처리하고, 다시 재생할 때 호스트의 최신 위치로 이동
- 호스트 커버 캐시와 세션 artwork URL/Base64를 게스트 음악 시트에 반영
- 곡 전환 후 늦게 도착한 artwork도 같은 playback event에서 재동기화
- 게스트 음악 시트를 같이 듣기 시트와 동일한 artwork 렌더링 경로로 통합
- 게스트 시트가 열릴 때 현재 곡의 artwork를 스토어 ID 또는 제목·아티스트로 보강 조회
- 일반 음악 시트의 앨범 `TabView` 드래그를 복구하고 도달 불가능했던 중복 커버 분기 제거
- 지도와 같이 듣기 화면에서 현재 세션 곡 및 참여자 상태가 stale 데이터로 남지 않도록 갱신

## 3. 기술적 고려 사항

- `ListenTogetherViewModel`이 호스트 브로드캐스트와 게스트 동기화 상태를 관리한다.
- `RunningMusicViewModel`은 ApplicationMusicPlayer 큐와 artwork URL 캐시를 관리한다.
- artwork는 세션 Base64, 세션 URL, 로컬 MusicKit artwork, 카탈로그 보강 순서로 처리한다.
- 위치 갱신만으로 게스트 큐를 반복 재생성하지 않고 playback event 기준으로 곡 전환을 처리한다.
- 게스트 로컬 일시정지는 Firebase 세션 값을 변경하지 않아 호스트 재생에 영향을 주지 않는다.
- 기존 일반 재생의 앨범 드래그와 단독 재생 경로는 별도 분기로 유지한다.
