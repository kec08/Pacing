# Issue #102 최종 개발 보고서

## 작업 결과

- 같이 듣기 RTDB 세션에 호스트·게스트 프로필 이미지 스냅샷을 추가했다.
- 요청 배너와 같이 듣기 시트가 실제 프로필 사진을 사용하고, 누락·손상된 이미지는 이니셜 아바타로 대체한다.
- 지도 내 내 러너와 친구 러너의 음악 카드 및 음표 원형 배지를 기존 내 카드의 진한 버건디 표면으로 통일했다.
- 페이스 계산에 유효 구간 필터(속도·정확도 기반 거리)와 최소 누적 거리 20m 조건을 추가했다.
- 러닝/일시정지 중 내 위치 버튼을 통계 패널 아래 우측의 상위 레이어에 표시하고, 탭 시 자동 추적을 재개한다.

## 검증

- Firebase Realtime Database 규칙 변경은 없다.
- 기존 세션 데이터는 호환되며 이미지가 없으면 이니셜 폴백을 사용한다.
- 실제 기기에서 두 계정의 같이 듣기와 위치 이동 수동 QA가 필요하다.
