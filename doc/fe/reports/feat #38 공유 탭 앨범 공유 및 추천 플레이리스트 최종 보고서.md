## 구현 요약

기존 placeholder 상태였던 공유 탭을 실제 음악 탐색 화면으로 교체했다.  
이제 공유 탭에서는 친구가 공유한 플레이리스트 스냅샷을 카드 형태로 보고, 상세 화면에서 트랙 목록을 확인하고 앱 내부에 저장할 수 있다.

동시에 Apple Music 추천 플레이리스트와 추천 스테이션도 함께 노출되도록 구성했다.  
추천 플레이리스트 상세에서는 전체 재생과 Apple Music 라이브러리 저장을 지원하고, 친구 플레이리스트는 `songStoreID` 기반 곡 큐 재생과 앱 내부 저장을 지원한다.

## 계획서 대비 변경 사항

| 항목 | 계획 | 실제 구현 | 사유 |
|------|------|-----------|------|
| 친구 플레이리스트 데이터 | 공유 문서 + 트랙 별도 저장 | 공유 문서에 트랙 스냅샷을 inline 저장 | MVP에서 Firestore 구조를 단순화하고 상세 조회를 빠르게 하기 위해 |
| 친구 플레이리스트 저장 | 앱 내부 저장 + 후속 확장 | 앱 내부 저장만 우선 구현 | 친구 플레이리스트 원본이 Apple Music 공용 카탈로그가 아닐 수 있어 라이브러리 저장 보장이 어려움 |
| 추천 스테이션 상세 | 상세 화면 가능성 검토 | 메인에서 즉시 재생 중심으로 구현 | 사용자 요청 핵심이 플레이리스트 상세였고 스테이션은 빠른 재생 UX가 더 적절하다고 판단 |

## 알려진 제한사항

- 친구 플레이리스트는 Apple Music 친구 소셜 데이터가 아니라 앱 내부 동기화 스냅샷 기준이다.
- 친구 플레이리스트의 `전체 재생`은 저장된 `songStoreID`가 유효한 경우에만 동작한다.
- 추천 결과는 Apple Music 구독 상태, 스토어프론트, 계정 상태에 따라 달라질 수 있다.
- GitHub 이슈 생성과 원격 PR 생성은 현재 `gh auth` 토큰 만료로 이 로컬 작업 시점에는 진행하지 못했다.
