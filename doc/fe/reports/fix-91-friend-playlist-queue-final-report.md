# 친구 플레이리스트·앨범 개별 곡 연속 재생 최종 개발 보고서

> **완료일**: 2026-08-05
> **관련 이슈**: #91
> **PR**: 미생성
> **브랜치**: `fix/91-friend-playlist-queue`

## 구현 요약

친구 플레이리스트·앨범 상세에서 개별 곡을 선택할 때, 선택 곡부터 남은 수록곡을 순서대로 포함한 Apple Music 재생 큐를 구성하도록 수정했다.

## 구현된 기능 목록

- [x] 개별 곡 선택 시 선택 곡부터 마지막 곡까지 재생 큐 구성
- [x] 친구 플레이리스트와 앨범 상세의 개별 곡 재생 경로 통합
- [x] 선택한 곡이 재생 불가할 때 다음 곡을 임의로 재생하지 않는 오류 처리
- [x] 다음 곡 전환 시 수록곡 강조 및 미니플레이어 표시 동기화
- [x] 노래 탭 미니플레이어·수록곡 목록의 곡 전환 애니메이션
- [ ] Apple Music이 연결된 실기기에서 연속 재생 회귀 QA

## 계획서 대비 변경 사항

| 항목 | 계획 | 실제 구현 | 사유 |
|---|---|---|---|
| 재생 큐 구성 | 공통 재생 계층에서 선택 인덱스부터 큐 구성 | `AppleMusicRecommendationService`에 선택 곡 ID 기반 큐 API 추가 | 기존 상세 화면별 단일 곡 재생 경로를 최소 변경으로 통합 |
| 재생 불가 선택 곡 | 기존 오류 UX 유지 | 선택 곡 해석 성공 여부를 먼저 확인 | 다음 곡이 의도치 않게 재생되는 것을 방지 |
