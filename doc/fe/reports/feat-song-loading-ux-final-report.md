## 구현 요약

노래 탭의 Apple Music 추천 데이터가 로드되는 동안 오류 카드 대신 스켈레톤 UI를 유지하고, 일시적인 실패는 재시도 후 최종 실패일 때만 오류 얼럿으로 안내하도록 개선했습니다. 이후 확인된 플레이리스트·러닝 음악 전환 문제도 함께 보완했습니다.

## 구현된 기능 목록

- [x] 장르·무드 섹션의 추천 로딩 스켈레톤 표시
- [x] 추천·구독 상태 조회의 제한 재시도
- [x] 장르·무드·개인화·차트 요청의 독립 실패 처리
- [x] 최신 요청만 UI 상태를 반영하도록 보호
- [x] 상단 `내 플레이리스트 동기화` 버튼 제거
- [x] Pull-to-refresh 내 플레이리스트 동기화 유지
- [x] 플레이리스트 대표 이미지와 수록곡 앨범 커버의 대체 표시 분리
- [x] 공유 플레이리스트 상세 진입 시 저장된 곡 목록 즉시 표시
- [x] 러닝 화면에서 플레이리스트 선택 시 재생 큐를 먼저 교체
- [x] 다음/이전 곡 전환 시 커버·제목·아티스트 상태 동기화

## 계획서 대비 변경 사항

| 항목 | 계획 | 실제 구현 | 사유 |
|------|------|-----------|------|
| 중복 요청 처리 | 최종 실패만 노출 | 최신 요청 식별자 추가 | 새로고침/초기 진입 요청 경합에서 오래된 오류 노출 방지 |
| 추천 요청 처리 | 묶음 요청 재시도 | 섹션별 응답을 독립 처리 | 하나의 카탈로그 검색 실패가 전체 추천 실패가 되는 문제 해결 |
| 플레이리스트 상세 | 카탈로그 보강 후 표시 | 저장된 스냅샷 즉시 표시 | 제목 기반 재검색으로 유사 곡이 매핑되고 진입이 늦어지는 문제 해결 |
| 러닝 재생 전환 | 수록곡/커버 보강 후 큐 설정 | 시스템 재생 큐를 먼저 교체 | 네트워크 보강 대기 동안 이전 곡이 유지되는 문제 해결 |
