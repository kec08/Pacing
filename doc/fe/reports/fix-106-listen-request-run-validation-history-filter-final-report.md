## 구현 요약

같이 듣기 요청에 최신 발신자 프로필 이미지를 반영하고 다크 모드 요청 배너의 흰색 외곽선을 제거했다. 짧은 거리 및 비정상 페이스 기록은 표시와 통계에서 안전하게 제외하도록 공통 유효성 정책을 적용했다. 또한 `main`에만 반영돼 있던 PR #97의 최근 활동 월별 필터를 현재 개발 기준인 `dev` 코드에 이관하고, 월별 목록에서 기존의 5개 기본 표시와 더보기/접기 흐름을 유지했다.

## 구현된 기능 목록

- [x] 같이 듣기 요청 전 Firestore의 최신 발신자 프로필 이미지를 조회하고, 실패 시 로컬 캐시로 폴백한다.
- [x] 수신 요청 배너의 고정 흰색 테두리를 제거해 다크 모드 표면을 정리한다.
- [x] 0.10km 미만 또는 30분/km 초과 러닝 기록의 페이스를 `--'--\"`으로 표시한다.
- [x] 무효 기록을 마이·홈·친구 프로필 평균 페이스에서 제외하고, 유효 기록의 총 시간÷총 거리로 평균을 계산한다.
- [x] 신규 무효 기록은 이력 자체는 보존하되 페이스와 랩 페이스를 정규화한다.
- [x] 최근 활동에 기록이 있는 연·월별 필터를 적용하고 미래 기록을 제외한다.
- [x] 선택 월은 기본 5개 표시, `더보기 (N개)` 및 `접기`로 전체 기록을 확인한다.
- [x] 페이스 유효성 경계값 단위 테스트를 추가한다.

## 알려진 제한사항

- 러닝 이력 조회 한도는 기존과 같이 최근 100개다. 이 범위를 넘는 월별 이력은 별도의 페이지네이션 개선이 필요하다.
- 이미 저장된 무효 기록은 데이터 삭제 없이 조회·표시·통계 단계에서 제외한다.
- 프로필 이미지 반영은 Firestore 조회 성공 여부와 네트워크 상태에 따라 캐시 또는 이니셜 폴백을 사용한다.
- 라이트/다크 모드 실기기 UI 확인 및 실제 A→B 같이 듣기 요청 검증이 남아 있다.
