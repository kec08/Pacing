# #72 친구 플레이리스트 전체 커버 및 이미지 로딩 최적화 최종 보고서

> **상태**: 완료
> **관련 이슈**: #72
> **브랜치**: `feat/72-music-artwork-performance`

## 결과

- 친구 플레이리스트의 누락된 수록곡 커버를 전체 보강하도록 변경했다.
- 카탈로그 식별자 배치 조회 후 누락 곡은 최대 4개씩 병렬 검색해 순차 대기를 줄였다.
- 목록은 대표 커버 한 장만 빠르게 보강하고, 상세에서만 전체 수록곡을 보강해 첫 진입을 보호했다.
- 이미지 로더에 중복 요청 병합, 메모리·디스크 캐시, ImageIO 다운샘플링, 제한 병렬 프리패치를 적용했다.
- 상세 플레이리스트 결과를 계정·플레이리스트·업데이트 시각별로 10분간 캐시해 재진입 시 즉시 표시한다.
- 홈 친구 최근 음악 영역은 카드 박스를 제거하고 작은 앨범 타일에 친구 이름·곡 제목·가수를 표시하도록 개선했다.

## 제한 사항

- Apple Music 카탈로그에 매칭되지 않는 곡은 의도적으로 플레이스홀더를 유지한다.
- 상세 데이터 캐시는 같은 앱 실행 중 10분간 보관된다. 앱을 다시 실행한 뒤에도 이미지 데이터는 URL 캐시 정책에 따라 재사용된다.
