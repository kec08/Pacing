## 구현 요약

홈 화면의 데이터 요청을 섹션별로 분리하고 Realtime DB 조회의 시간 제한을 추가해 무한 스켈레톤을 제거했다. 친구 플레이리스트의 빈 문자열 커버 URL을 누락값으로 처리하고, 대표·수록곡 커버를 Apple Music 카탈로그로 보강하도록 개선했다.

## 구현된 기능 목록

- [x] 홈 러닝·같이 듣기 섹션별 로딩 및 오류 상태 분리
- [x] Realtime DB 단건 조회 취소 콜백 및 10초 타임아웃
- [x] 홈 섹션별 오류 카드와 재시도 버튼
- [x] 빈 문자열 커버 URL의 대표·수록곡 커버 폴백
- [x] 누락 수록곡 커버 최대 8곡 카탈로그 보강
- [x] 이미지 요청 취소 시 이전 이미지가 새 카드에 표시되는 경합 방지

## 계획서 대비 변경 사항

| 항목 | 계획 | 실제 구현 | 사유 |
|---|---|---|---|
| 친구 플레이리스트 커버 영속화 | 조회 중 보강 결과를 Firestore 병합 저장 | 조회 화면·메모리 캐시에서만 보강, 소유자 동기화 시에만 원본 저장 | Firestore 규칙이 타인 공유 문서의 수정을 차단 |
| 홈 요청 안정화 | 섹션별 상태와 종료 보장 | 섹션별 상태, 취소 콜백, 10초 타임아웃, 재시도 UI | Realtime DB 응답 미완료 경로를 명시적으로 해소 |

## 알려진 제한사항

- 친구의 공유 플레이리스트 문서는 보안 규칙상 소유자만 갱신할 수 있어, 타인 조회 중 보강한 메타데이터는 원본 Firestore에 기록하지 않는다.
- Apple Music 권한이 없거나 카탈로그 검색에 실패한 경우에는 기존 음표 플레이스홀더를 유지한다.
- 인증된 Firebase 및 Apple Music 계정을 통한 실기기 UI QA가 남아 있다.
