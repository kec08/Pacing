## 구현 요약

러닝 중 및 일시정지 상태의 정보 표시와 지도 인터랙션을 Nike Run Club 스타일의 정보 위계에 맞춰 개선했습니다. 러닝 중에는 3개 지표를 각각 독립적으로 전환할 수 있고, 일시정지 시에는 지도와 6개 지표·컨트롤을 함께 확인할 수 있도록 구성했습니다.

## 구현된 기능 목록

- [x] 러닝 중 거리·페이스·칼로리 지표의 개별 탭 전환 및 애니메이션
- [x] 일시정지 시 6개 지표(거리·평균 페이스·시간·칼로리·고도 상승·BPM) 동시 표시
- [x] 일시정지 화면 하단 패널 및 재개/종료 컨트롤 애니메이션
- [x] 다크 모드용 `backgroundPrimary` 배경 적용
- [x] 구분선 폭·두께·끝처리 및 지표 수직 정렬 개선
- [x] 러닝/일시정지 상태에서 내 위치 버튼을 고정 오버레이로 표시
- [x] 일시정지 상태에서 핀이 지도에 보이는 영역 중앙에 오도록 카메라 보정
- [x] 누적 거리 기준 1km 마커 보간 계산기 추가
- [x] 유효 수직 정확도와 최소 상승량 기준의 고도 상승 계산기 추가
- [x] 1km 마커·고도 계산 단위 테스트 추가
- [ ] HealthKit Apple Watch 심박수, CMPedometer 케이던스, WeatherKit 날씨, 결과 화면 저장 연동

## 알려진 제한사항

- 현재 고도 상승·BPM·케이던스는 실제 센서 연동 전까지 `--`로 표시됩니다. 임의 값이나 추정값은 사용하지 않습니다.
- HealthKit Apple Watch 심박수, `CMPedometer` 케이던스, WeatherKit, Firestore 저장 및 결과 상세 화면 연결은 후속 구현 범위입니다.
- 현재 1km 계산기는 검증된 누적 거리 샘플 사이의 경계 좌표를 생성하며, 지도 annotation 표시는 후속 연결이 필요합니다.
- `UIScreen.main` 사용은 현재 빌드에는 영향을 주지 않지만, 화면 컨텍스트 기반 높이 계산으로 교체하는 것이 좋습니다.
- 기존 작업 트리의 `Info.plist`, 삭제된 이미지, `output/`, `tmp/` 변경은 이번 PR 범위에서 제외합니다.
