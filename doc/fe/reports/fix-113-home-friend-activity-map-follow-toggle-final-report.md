## 1. 문제 및 원인

- 다른 계정에서 친구가 있어도 홈의 친구 최근 러닝·음악 섹션 전체가 오류로 표시됐다.
- 친구 활동 문서가 비공개이거나 읽기 권한이 없는 친구 한 명의 조회 오류가 `fetchFriendsRecentRuns`, `fetchFriendsRecentSongs` 전체로 전파된 것이 원인이다.
- 지도 내 위치 버튼은 자동 추적을 켤 수만 있고 해제할 수 없었다.

## 2. 변경 사항

### 홈 친구 활동

- 친구 목록 문서 조회 실패는 기존처럼 상위 오류로 전파한다.
- 각 친구의 최근 러닝·음악 조회 실패는 해당 친구만 결과에서 제외한다.
- 따라서 공개 범위가 다른 친구가 섞여 있어도 조회 가능한 친구 활동은 홈에 계속 표시된다.

### 지도 내 위치 추적

- 내 위치 버튼을 자동 추적 켜기/끄기 토글로 변경했다.
- 해제 시 현재 카메라 위치를 유지하고, 재활성화 시 현재 위치로 재중심화한다.
- idle·러닝·일시정지 상태에서 위치 업데이트에 동일하게 반응하며, 접근성 레이블과 값도 현재 상태에 맞춘다.

### 지도 러너 음악 말풍선

- 라이트 모드에서는 정보 말풍선 표면을 흰색으로 표시한다.
- 다크 모드의 기존 버건디 표면은 유지한다.
- 내 핀의 이름은 라이트·다크 모드 모두 메인 핑크로 강조한다.

## 3. 검증

- 내 위치 추적 토글과 지도 드래그 해제 경로를 코드 검토
- Xcode 빌드는 현재 개발자 디렉터리가 Command Line Tools(`/Library/Developer/CommandLineTools`)로 설정되어 있어 실행하지 못했다.
