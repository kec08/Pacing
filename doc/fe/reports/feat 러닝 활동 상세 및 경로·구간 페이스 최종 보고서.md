## 구현 요약

홈의 최근 러닝과 마이페이지의 최근 활동 카드를 공통 활동 상세 화면으로 연결했다.
상세 화면에서 거리, 시간, 평균 페이스, 추정 칼로리, 이동 경로를 제공하고, 별도 화면에서 km별 페이스를 확인할 수 있다.

새 러닝은 종료 시점의 확정 km 랩 페이스를 Firestore에 함께 저장한다. 기존 기록은 랩 페이스·경로가 없어도 빈 상태로 안전하게 상세 화면을 연다.

## 구현된 기능 목록

- [x] `RunRecord`에 km 랩 페이스 모델 추가
- [x] `FirestoreService`의 랩 페이스 저장·조회 및 기존 문서 호환 처리
- [x] 러닝 종료 저장 시 확정 랩 페이스 스냅샷 전달
- [x] 거리/시간/평균 페이스/칼로리/완료 구간을 보여주는 활동 상세 화면
- [x] MapKit 경로 폴리라인과 출발·도착 마커, 경로 없는 기록의 빈 상태
- [x] 상대 막대로 속도 차이를 보여주는 구간별 페이스 화면
- [x] 홈 최근 러닝과 마이페이지 최근 활동의 공통 상세 화면 연결
