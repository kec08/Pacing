## 구현 요약

홈의 최근 러닝과 마이페이지의 최근 활동 카드를 공통 활동 상세 화면으로 연결했다.
상세 화면에서 거리, 시간, 평균 페이스, 추정 칼로리, 이동 경로와 km별 페이스를 한 화면에서 제공한다.

새 러닝은 종료 시점의 확정 km 랩 페이스를 Firestore에 함께 저장한다. 기존 기록은 랩 페이스가 없어도 거리와 평균 페이스를 바탕으로 1km 단위 행을 표시하며, 경로가 없을 때는 빈 상태를 제공한다.

- [x] 러닝 종료 저장 시 확정 랩 페이스 스냅샷 전달

- [x] MapKit 경로, 출발·도착 둥근 레이블, 경로 없는 기록의 빈 상태
- [x] 상세 화면에서 바로 확인하는 km별 구간 페이스
- [x] 홈 최근 러닝과 마이페이지 최근 활동의 공통 상세 화면 연결

## 알려진 제한사항

- 고도·심박·케이던스는 현재 앱에서 수집하지 않으므로 상세 화면에 포함하지 않았다.
- 기존 기록의 구간 페이스는 실제 랩 데이터가 없으므로 평균 페이스로 추정해 표시한다.
- 지도 타일은 네트워크 연결 상태에 영향을 받는다.
- Apple 지도의 `Maps Legal`/`Legal` 표기는 지도 데이터 라이선스상 MapKit이 제공하는 필수 문구로, 제거·글자 크기 조절·문구 변경이 불가능하다.
