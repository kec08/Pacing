## 구현 요약

마이 탭의 러닝 이력을 기록 월 기준으로 탐색할 수 있게 개선하고, 선택 월에는 최신 5개를 먼저 보여준 뒤 `모두보기`/`접기`로 확장하도록 했다. 친구 음악 화면과 플레이리스트 상세의 재생 상태 표현을 정리하고, 미니 플레이어의 이전·재생/정지·다음 제어를 Application Music Player와 시스템 플레이어 양쪽에 대응하도록 보완했다. 테마 진입 행과 지도 러너 음악 카드의 라이트·다크 표면색도 실기기 피드백에 맞춰 조정했다.

## 구현된 기능 목록

- [x] 러닝 기록이 존재하는 월만 최신순 `N월` 칩으로 가로 표시
- [x] 미래 날짜 기록 제외 및 선택 월별 최신순 정렬
- [x] 선택 월 기본 5개 노출, `모두보기`/`접기` 전환
- [x] 마이 탭 설정 행을 아이콘·chevron·구분선 없는 `테마` 텍스트 행으로 정리
- [x] 친구가 듣는 음악 카드를 최근 앨범과 같은 커버·제목·친구 이름 구조로 통일
- [x] 친구 플레이리스트 상세의 재생 중 곡 커버에 검정 오버레이와 기존 파형 유지
- [x] 친구 프로필 최근 노래의 Apple Music 재생 및 재생 상태 피드백 유지
- [x] 미니 플레이어 이전 곡·재생/정지·다음 곡 제어 추가 및 Application Music Player 대응
- [x] 마지막/단일 곡에서 다음 곡 선택 시 재생 정지 처리
- [x] 지도 러너 음악 카드의 라이트 모드 흰색 표면 및 다크 모드 배지·카드 표면 통일
- [x] 친구 음악 카드 스켈레톤을 실제 앨범 커버 레이아웃과 동일하게 조정
