## 변경 내용

### 고도 상승

- 실제 이동이 승인된 위치 샘플만 고도 계산에 사용한다.
- 수직 정확도 10m 이하의 샘플만 사용한다.
- 5개 샘플 중앙값으로 GPS 고도 노이즈를 완화한다.
- 5m 이상 상승이 2회 연속 확인될 때만 상승으로 누적한다.
- 샘플 간 상승량은 최대 12m로 제한한다.
- 전체 상승량은 이동거리 기준 최대 30m/km로 제한한다.
- 이동거리가 짧거나 신뢰할 수 있는 고도 샘플이 부족하면 과대값 대신 0m 또는 `--`로 표시한다.

### 평균 페이스

- 전체 경과 시간과 실제 이동 시간을 분리한다.
- 평균 페이스는 `실제 이동 시간(분) ÷ 실제 이동 거리(km)`로 계산한다.
- 일시정지·GPS 대기·정지 구간은 평균 페이스 계산에서 제외한다.
- 0.10km 미만 기록은 페이스를 표시하지 않는다.
- 신규 기록에는 실제 이동 시간을 저장한다.
- 기존 기록에 이동 시간이 없으면 구간별 페이스를 이용해 보정한다.

### 월·주간 결산

- 15분/km보다 느린 기록은 대기 또는 GPS 미수신 기록으로 분류한다.
- 비정상 기록은 평균 페이스·총거리·러닝 횟수·총시간 결산에서 제외한다.
- 평균 페이스는 기록별 단순 평균이 아니라 거리 가중 방식으로 계산한다.
- 비정상 기록 자체는 활동 이력에서 삭제하지 않는다.

### 케이던스

- 종료 시 조회 데이터가 없어도 마지막 실시간 케이던스 또는 누적 평균을 보존한다.
- 일시정지·재개와 센서 누적값이 초기화되는 경우를 처리한다.

## 실기기 QA 항목

1. 동작 및 피트니스 권한을 허용한 뒤 1km 이상 러닝한다.
2. 고도 상승이 평지에서 급격히 100~200m 이상 증가하지 않는지 확인한다.
3. 일시정지 후 재개했을 때 평균 페이스에 정지 시간이 포함되지 않는지 확인한다.
4. 케이던스가 러닝 중 숫자로 표시되고 종료 결과에도 저장되는지 확인한다.
5. 러닝 종료 후 월 결산에서 비정상 기록이 평균 페이스를 왜곡하지 않는지 확인한다.
