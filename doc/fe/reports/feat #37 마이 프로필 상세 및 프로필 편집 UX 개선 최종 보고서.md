## 구현 요약

마이 탭 상단의 프로필 헤더를 단순 표시 영역이 아니라 `내 프로필 상세` 진입점으로 바꿨다.  
이제 사용자는 좌상단 프로필 이미지 또는 이름 영역을 탭해 친구 프로필과 유사한 구조의 상세 화면으로 이동할 수 있고, 그 안에서 러닝 요약 지표와 최근 들은 노래를 한 번에 확인할 수 있다.

프로필 수정 흐름도 설정 리스트에서 분리해 상세 화면의 주요 CTA로 재구성했다.  
편집 화면은 기존 휠 피커 중심 시트에서 벗어나, 큰 프로필 이미지와 리스트형 입력 구조를 사용하는 인스타그램식 프로필 편집 흐름으로 정리했고 기본 입력 검증과 저장 실패 안내를 함께 보강했다.

## 알려진 제한사항

- 프로필 편집은 현재 닉네임 / 사진 / 나이 / 키 / 몸무게만 다룬다. 온보딩의 다른 속성은 이번 범위에 포함하지 않았다.
- 최근 들은 노래는 현재 저장된 `recentSongs` 기준으로만 노출된다. 정렬/필터 고도화는 후속 개선 범위다.
- 내 프로필 상세 화면은 친구 프로필과 시각 구조를 맞췄지만, 완전한 공통 컴포넌트화는 아직 적용하지 않았다.
